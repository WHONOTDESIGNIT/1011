## 3. 语言风格规范（B2B 制造商网站）

### 3.1 句式与礼貌体
- 全站使用 **شما 尊称**（波斯 B2B 标准），动词按 شما 变位；避免 "تو" 亲称。
- 波斯语 RTL 书写；数字保留西方数字。
- 专有名词保留英文原样：iShine、Costco、RoseSkinCo、KU2、Lumi、Venus、Alpha、Euno、Hestia、Themis、Emerald、Wooden、IPL、OEM、ODM、FDA、CE、MOQ、B2B、FWHM、UV、LED、AI、SKU、ISO 编号、Shenzhen、Guangzhou。
- private label → **برند خصوصی / لیبل خصوصی**。

### 3.2 标点与格式
- 波斯数字：可保留西方数字（波斯电商通用）或波斯-阿拉伯数字（۰۱۲۳）。
- 货币：**تومان (تومان)** 或 USD。
- 百分比：**۷۰٪** 或 **70 %**。
- 温度：**۱۰ درجه سانتی‌گراد** 或 **10 °C**。
- 引号用 **« »**（波斯文引号）。
- **HTML 标签保留**（`<b>`、`<br>`），只翻译内部文本。

### 3.3 术语一致性铁律
- IPL hair removal device → **دستگاه حذف مو با IPL / دستگاه اپیلاسیون IPL**
- hair removal → **حذف مو**；body hair → **مو**；hair（头发）→ **مو**（同词靠上下文）
- flash → **فلاش**；flash count → **تعداد فلاش**
- skin tone → **رنگ پوست**；skin → **پوست**
- painless → **بدون درد**
- 禁止英文残留：device→دستگاه、handset→دستگاه/دستگاه دستی、unit→واحد
