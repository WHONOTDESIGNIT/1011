## 3. 语言风格规范（B2B 制造商网站）

### 3.1 句式与礼貌体
- 全站使用正式阿拉伯语（الفصحى，MSA），B2B 语气；避免方言（海湾方言仅限消费者品牌）。
- 称呼客户用 **العميل / العملاء**（客户）。
- 专有名词保留英文原样：iShine、Costco、RoseSkinCo、KU2、Lumi、Venus、Alpha、Euno、Hestia、Themis、Emerald、Wooden、IPL、OEM、ODM、FDA、CE、MOQ、B2B、FWHM、UV、LED、AI、SKU、ISO 编号、Shenzhen、Guangzhou。
- private label → **العلامة الخاصة / العلامة التجارية الخاصة**。

### 3.2 标点与格式
- 阿拉伯语数字：可保留西方数字（阿拉伯-印度数字在东/西海湾混用，B2B 用西方数字更清晰）。
- 货币：**ر.س**（沙特里亚尔）、**د.إ**（迪拉姆）或 USD；站点统一按语境。
- 百分比：**70٪** 或 **70 %**（% 前空格，阿拉伯语规范）。
- 温度：**10 درجة مئوية** 或 **10 °C**。
- 引号用 **" "**；**HTML 标签保留**（`<b>`、`<br>`），只翻译内部文本。

### 3.3 术语一致性铁律
- IPL hair removal device → **جهاز إزالة الشعر بتقنية IPL**
- hair removal → **إزالة الشعر**；body hair → **شعر الجسم**；hair（头发）→ **شعر**
- flash → **ومضة**（不可用 "فلاش" 音译）；flash count → **عدد الومضات**
- skin tone → **لون البشرة / درجة لون البشرة**
- painless → **دون ألم**（统一）
- 禁止英文残留：device→جهاز、handset→جهاز/وحدة、unit→وحدة
