## 3. 语言风格规范（B2B 制造商网站）

### 3.1 句式与礼貌体
- 全站使用 **εσείς 尊称**（希腊 B2B 标准），动词按 εσείς 变位；避免 "εσύ" 亲称。
- 专有名词保留英文原样：iShine、Costco、RoseSkinCo、KU2、Lumi、Venus、Alpha、Euno、Hestia、Themis、Emerald、Wooden、IPL、OEM、ODM、FDA、CE、MOQ、B2B、FWHM、UV、LED、AI、SKU、ISO 编号、Shenzhen、Guangzhou。
- private label → **ιδιωτική ετικέτα / προϊόν ιδιωτικής ετικέτας**。

### 3.2 标点与格式
- 希腊数字：千位分隔用点（1.999.998）或空格，统一为点；小数用逗号（2,5）。
- 货币：**€** 或 USD。
- 百分比：**70 %**。
- 温度：**10 °C**。
- **HTML 标签保留**（`<b>`、`<br>`），只翻译内部文本。

### 3.3 术语一致性铁律
- IPL hair removal device → **συσκευή αποτρίχωσης IPL**
- hair removal → **αποτρίχωση**；body hair → **τρίχες**；hair（头发）→ **μαλλιά**（不可混用 τρίχες/μαλλιά！τρίχες=体毛，μαλλιά=头发）
- flash → **λάμψη**（不用 flash/φλας）；flash count → **αριθμός λάμψεων**
- skin tone → **τόνος δέρματος**；skin → **δέρμα**
- painless → **ανώδυνος**
- 禁止英文残留：device→συσκευή、handset→συσκευή、unit→μονάδα

## 4. 已发现的机翻痕迹（子代理复核重点）

1. **flash/φλας 残留**（4 处）：统一 λάμψη。
2. **εσύ/εσείς 混用**：统一 εσείς。
3. **τρίχες/μαλλιά 混用风险**：体毛=τρίχες，头发=μαλλιά。
4. **希腊语性数一致**：名词阴阳中性。
5. `develo*` 部分保留英文（339 处与英文相同）：专有名词保留合理，其余确认。
