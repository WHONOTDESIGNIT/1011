## 3. 语言风格规范（B2B 制造商网站）

### 3.1 句式与礼貌体
- 全站使用 **вы 尊称**（俄语 B2B 标准），动词按 вы 变位；名词称呼客户用 **клиент / клиенты**。
- 禁止 "ты" 亲称（消费者品牌可用，B2B 制造商一律 вы）。
- 专有名词保留英文原样：iShine、Costco、RoseSkinCo、KU2、Lumi、Venus、Alpha、Euno、Hestia、Themis、Emerald、Wooden、IPL、OEM、ODM、FDA、CE、MOQ、B2B、FWHM、UV、LED、AI、SKU、ISO 编号、Shenzhen、Guangzhou。
- 俄语行业术语：private label → **собственная торговая марка (СТМ)** 或 **частная марка**；供应链术语保留行业惯用（FOB、CIF、SKU、MOQ）。

### 3.2 标点与格式
- 俄语数字：千位分隔用空格（1 999 998）或点（1.999.998），统一为空格；小数用逗号（2,5）。
- 货币：**₽**（卢布）或按语境 USD；价格格式 "34,95 €/мес" 类保留。
- 百分比：**70 %**（% 前空格，俄语规范）。
- 温度：**10 °C**（° 前空格）。
- 能量/面积：6 J/cm²、6,2 cm²（小数逗号）。
- 引号：俄语用 **« »**（кавычки-ёлочки）。
- **HTML 标签保留**（`<b>`、`<br>`），只翻译内部文本。

### 3.3 术语一致性铁律
- IPL hair removal device → **фотоэпилятор**（产品）/ **IPL-устройство**（泛指）
- hair removal → **удаление волос**；body hair → **волосы на теле**（волосы=毛发通用）；hair（头发）→ **волосы**（同一词，靠上下文区分）
- flash → **вспышка**（不可用 "флэш" 音译）；flash count → **количество вспышек**
- skin tone → **тон кожи**；skin → **кожа**
- painless → **безболезненный**
- 禁止 "флэш" 音译 flash；禁止英文残留（device→устройство、handset→устройство/прибор、unit→устройство）

## 4. 已发现的机翻痕迹（子代理复核重点）

1. **"IPL-устройство для удаления волос" 直译**（21 处已修，泛指语境剩余）：产品名必须 фотоэпилятор。
2. **вспышка 与 флэш 混用风险**：需全库检查无 флэш 音译。
3. **ты/вы 混用**：需检查无 ты 亲称。
4. **俄语格变化错误**：形容词与名词性数格配合（如 "IPL-устройства" 后接形容词）。
5. **英文语序残留**：俄语介词短语位置、长句结构调整。
6. `develo*` 部分保留英文（289 处与英文相同）：专有名词保留合理，其余确认。
