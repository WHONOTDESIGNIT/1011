## 3. 语言风格规范（B2B 制造商网站）

### 3.1 句式与礼貌体
- 全站使用泰语礼貌体：句尾 **ครับ**（男性）/ **ค่ะ**（女性）通常省略（B2B 网站用中性正式体），动词用正式体。
- 称呼客户用 **ลูกค้า**（客户）/ **คุณ**（您）。
- 专有名词保留英文原样：iShine、Costco、RoseSkinCo、KU2、Lumi、Venus、Alpha、Euno、Hestia、Themis、Emerald、Wooden、IPL、OEM、ODM、FDA、CE、MOQ、B2B、FWHM、UV、LED、AI、SKU、ISO 编号、Shenzhen、Guangzhou。
- private label → **แบรนด์ส่วนตัว / เซอร์วิสแบรนด์**。

### 3.2 标点与格式
- 泰语数字：可保留西方数字（泰语电商通用）。
- 货币：**บาท (฿)** 或 USD。
- 百分比：**70%** 或 **70 %**。
- 温度：**10°C** 或 **10 องศาเซลเซียส**。
- 泰语无空格分词（泰文连续书写），但数字/英文与泰文之间留空格。
- **HTML 标签保留**（`<b>`、`<br>`），只翻译内部文本。

### 3.3 术语一致性铁律
- IPL hair removal device → **เครื่องกำจัดขน IPL**
- hair removal → **กำจัดขน**；body hair → **ขน**；hair（头发）→ **เส้นผม**（语境区分）
- flash → **แฟลช / แสงแฟลช**；flash count → **จำนวนแฟลช**
- skin tone → **โทนผิว**（不用 สีผิว）；skin → **ผิว**
- painless → **ไม่เจ็บปวด**（统一）
- 禁止英文残留：device→เครื่อง/อุปกรณ์、handset→เครื่อง、unit→เครื่อง
