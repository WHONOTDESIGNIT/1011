**Kort antwoord:** IPL-apparaten voor thuisgebruik circuleren in de handel onder minstens twee tariefcodes, 8510.30 en 8543.70, omdat geen van beide posten is geschreven met dit product in gedachten. De code bepaalt het douanerecht, de preferentiële behandeling en de rapportage, de douane-expediteur die de aangifte ondertekent neemt de beslissing, en het enige waar een koper op moet aandringen is dat elk document in de zending daarmee overeenkomt.

## De twee posten, en waarom ze allebei opduiken

De eerste post omvat scheerapparaten, haarclippers en ontharingsapparaten, en de eigen bewoording ervan veronderstelt een ingebouwde elektromotor. Dat past bij een scheerapparaat. Een IPL-apparaat heeft helemaal geen motor: een xenonlamp, een condensatorbank, een besturingsprint en een koelsysteem.

Die mismatch is de reden dat de restpost in dezelfde handel opduikt: elektrische machines en apparaten met een eigen functie, elders niet genoemd of niet inbegrepen. Het is de eerlijke thuisbasis voor een product dat het schema niet had voorzien.

Beide codes belanden in echte documenten. Bij één order van 504 eenheden met een gradiëntbehuizing stond op de exportaangifte de code voor ontharingsapparaten, stond op de productpagina's hetzelfde nummer als een Amerikaanse code, en stond op een tweede paklijst de restpost. Twee documenten, één zending, twee antwoorden.

Niets daarvan is ongewoon in deze productcategorie. Wat ongewoon is, is het vangen vóór de aangifte in plaats van erna.

## Waarom de code geen papieren detail is

Het douanerecht is een functie van drie dingen: de code, de oorsprong en het programma waarvoor de oorsprong in aanmerking komt. Verander één ervan en het getal in de landed cost verschuift.

| Wat de code beïnvloedt | Waarom |
|---|---|
| Douanerecht | Verschillende posten dragen verschillende tarieven, en het verschil is vaak groter dan de vracht |
| Preferentiële behandeling | Vrijhandelsovereenkomsten worden per post onderhandeld |
| Aanvullende tariefprogramma's | Maatregelen op basis van oorsprong worden toegepast per post, niet per productomschrijving |
| Invoervergunningen en normen | Sommige bestemmingen koppelen marktoezicht of registratie aan specifieke posten |
| Statistische rapportage en quota | De rapportage van de importeur zelf wordt per code ingediend |

De codekwestie is dus geen administratieve netheid. Het is het verschil tussen een landed cost die is berekend en een die is gegokt.

## Wie beslist er eigenlijk

De douane-expediteur die als aangever optreedt, doet de aangifte, en de aangifte is aan hem om te ondertekenen. Dat is geen formaliteit om omheen te werken; het is de reden dat een expediteur weigert een code te gebruiken die hij niet kan verdedigen.

Daaruit volgen drie dingen voor een koper:

- **Vraag de code schriftelijk op voordat de order wordt geplaatst**, niet op de handelsfactuur nadat de goederen al zijn vertrokken.
- **Vraag tegen welk tariefschema hij is gecontroleerd.** Een code die klopt volgens het Amerikaanse tariefschema is niet automatisch juist voor de exportaangifte in het land van oorsprong. Dat zijn twee verschillende tariefboeken, en ze mogen van mening verschillen.
- **Vraag wat er gebeurt als het model verandert.** Voeg een motor toe voor een roterende kop, haal de lamp weg voor een LED-variant, en de post kan mee verschuiven.

Een leverancier die alle drie beantwoordt, heeft dit eerder gedaan. Een leverancier die zegt 'wij gebruiken altijd één code', heeft je verteld dat hij nooit is geaudit.

## De consistentieregel

Dit is het deel dat zendingen eruit pikt, en het ligt volledig binnen de controle van een fabriek: **de handelsfactuur, de paklijst, het certificaat van oorsprong en de aangifte moeten allemaal dezelfde code dragen, en de goederen moeten overeenkomen met de omschrijving erachter.**

Een zending waarbij de factuur één post noemt en de aangifte een andere, is een discrepantie aan de grens. Het maakt niet uit welke van de twee juist was.

De andere helft is de omschrijving. Een aangegeven omschrijving als 'ontharingsapparaat' zit comfortabel onder de ene post en ongemakkelijk onder de andere. Omschrijvingen en codes moeten samen worden gekozen.

## Wat wij bij onze orders doen

Wij houden de code op de handelsdocumenten en stemmen hem af tegen de aangifte voordat de expediteur indient, en zo werd de discrepantie in die order van 504 eenheden gevangen in plaats van ontdekt in de haven. We gebruiken dezelfde code op de productpagina's, zodat een koper die de site leest en een expediteur die de factuur leest naar hetzelfde nummer kijken.

Wat we niet doen, is een klant vertellen hoe hoog zijn invoerrecht zal zijn. Dat antwoord hangt af van zijn tariefschema, zijn oorsprongsregels en de visie van zijn eigen expediteur, en wij zijn niet de partij die de aangifte ondertekent.

## Wat je moet vragen vóór de eerste zending

1. Welke code komt er op de handelsfactuur, en tegen welk schema is die gecontroleerd?
2. Is die code eerder gebruikt op een zending van exact dit model, en is die zonder vragen door de douane gekomen?
3. Als het model verandert, wie controleert de code dan opnieuw, en wanneer?
4. Kunnen de factuur, de paklijst, het certificaat van oorsprong en de aangifte onderling worden gecontroleerd voordat er wordt ingediend?

Vier vragen, één pagina met antwoorden, opgeborgen bij de order. Het is goedkoper dan een herclassificatie.

Als de zending naar een markt gaat met een eigen conformiteitsregime, is de code maar de helft van de aangiftedocumenten.
