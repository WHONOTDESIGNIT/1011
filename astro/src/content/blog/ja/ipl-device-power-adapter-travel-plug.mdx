**短い答え：** 市場ごとにプラグ規格が異なるため、5つの地域に出荷するIPLデバイスは、そのままだと5種類のAC-DCアダプターを必要とします。当社は代わりに1つのトラベルプラグを供給します。定格6A 250V、オプションで5V/1000mAのUSBポートを備え、銅ピン版と鉄ピン版を用意しているので、1つのSKUで米国、英国、EU、オーストラリア、日本をカバーできます。

## ソケット規格こそが本当の制約

IPLデバイスはDC電源を必要とし、壁のコンセントが供給するのはACです。どこかで変換しなければならず、その変換する側は、差し込むソケットに物理的に合わなければなりません。

単一市場の発想が破綻するのは、この後者の要件です。米国のプラグは平らなブレードが2枚並んでいます。英国タイプは角型のピンが3本あり、プラグ本体にヒューズが入っています。欧州はくぼんだソケットに丸ピンを使います。オーストラリアは斜めのブレード2枚がV字を成しています。日本は一見すると米国と同じに見え、いざとなれば差し込めますが、規格は独自の文書で定められており、電圧も120Vではなく100Vです。

5つの地域、5つの物理インターフェース。1つの固定アダプターを同梱するブランドは、どのカートンがどの市場に向かうかを予測し、その予測が工場を出た後も当たっていることを願うしかありません。外したときに失うのはアダプターの代金ではなくデバイス本体です。IPLデバイスは通電しなければテストできないからです。

インターフェースごとに規格が存在し、それは国際互換ではなく各国のものです。英国のプラグは[BS 1363](https://knowledge.bsigroup.com/products/bs-1363-1-plugs-and-socket-outlets-specification-for-rewirable-and-non-rewirable-fused-plugs)で定められ、プラグとソケットのタイプの国際的な分類は[IEC 60083](https://webstore.iec.ch/en/publication/522)に収められており、IECは国別の一覧を[World Plugs](https://www.iec.ch/world-plugs)として公開しています。

## 代わりに当社が供給するもの：1つのプラグで多くのソケットに対応

トラベルプラグは、どのバージョンでも電気的な中身は同じです。変わるのは、どこに差し込むかです。

| 項目 | 仕様 |
|---|---|
| 製品名 | グローバルトラベルプラグ |
| 電流 / 電圧 | 最大6A 250V |
| USB出力（オプション版） | DC 5V / 1000mA |
| 色 | 標準は白、黒は受注対応 |
| ピン材質 | 銅または鉄（バージョンによる） |
| 本体材質 | ABS樹脂 |
| 重量 | 約100〜120g |
| 寸法 | 約7.3×5.0×3.9cm |

6A 250Vという定格は、IPLデバイスが消費する量を十分に上回ります。IPLデバイスはパルス負荷で、アダプターはそのパルスを成形する部品ではないため、この部品に求められる電気的な要件は、突入電流を耐え、温度を上げないことが中心で、ピーク値に到達することではありません。パルスを成形する設計はデバイス本体の中にあり、その側面の仕様化については[電源部品のページ](/components/power-supply)でドライバ段とレギュレーション段を解説しています。

## 銅ピンと鉄ピン：その違いで実際に得られるもの

これはほとんどのブランドが尋ねてくる判断で、正直な答えには両面があります。銅のほうが導電性に優れます。価格も高く、カートンも小さくなります。

| | 銅ピン | 鉄ピン |
|---|---|---|
| 導電性 | 高く、接点での抵抗発熱が少ない | 低いが、この電流では十分 |
| 耐食性 | 良好で、長年の使用でも接点品質を保つ | めっき鉄は屋内なら問題ないが、湿潤な気候では厳しい |
| ピンの耐久性 | 繰り返しの抜き差しによる変形に強い | 軟らかく、無理に差し込むと曲がりやすい |
| 単価 | 高い | 低い |
| 梱包密度 | 1カートン100個 | 1カートン200個 |
| カートン重量 | 12〜15.5kg | 約20.5kg |
| カートン寸法 | 52×27×37.0cm | 50×48×36.5cm |

プレミアムデバイスなら銅。アダプターが箱に同梱される景品のような大量生産の付属品なら、鉄で役割は果たせ、運賃の計算も楽になります。USBバージョンは銅ピンを使います。追加の負荷を担う仕様だからです。ピン材質は、分解したときにサプライヤーの調達判断が見えてくる場所のひとつで、その他の箇所は[当社の部品は実際どこから来ているのか](/blog/components-that-stand-up-to-scrutiny)で扱っています。

## 認証

アダプターは**RoHS、CE、FCC**の認証を取得して供給されます。

この3つは名前よりも適用範囲で理解する価値があります。RoHSは電気機器に含まれる有害物質に関するEUの制限で、[欧州委員会](https://environment.ec.europa.eu/topics/waste-and-recycling/rohs-directive_en)が定めています。また、電源に接続する付属品のCEマークは[低電圧指令](https://single-market-economy.ec.europa.eu/sectors/electrical-and-electronic-engineering-industries-eei/low-voltage-directive-lvd_en)とRoHSの両方に該当します。FCC認証は米国の無線周波数放出に関するもので、[FCC規則のPart 15](https://www.ecfr.gov/current/title-47/chapter-I/subchapter-A/part-15)に規定されています。付属品1つの証明書ファイルは、市場投入に必要な書類のごく入口にすぎません。市場ごとの書類の段階は[IPLバリデーションサービス](/blog/ipl-validation-services)で整理しています。コンプライアンス部門が証明書そのものを必要とする場合は、見積もりの段階でお知らせください。アーカイブ版ではなく最新の一式をお送りします。

## USBバージョンと、まず確認すべき数字

USBポートがあるのは、IPLデバイスに給電しているのと同じもので旅行者がスマートフォンを充電できるようにするためです。USB出力は**DC 5V / 1000mA**です。

これがお客様にとって何を意味するか、はっきりしていますか。1000mAは1Aです。スマートフォンは充電できます。タブレットはまともな速度では充電できず、より大きな電流のハンドシェイクを前提とする機器は急速充電できません。USBポートが自分の電流容量をどう知らせるかという規格が存在するのは、まさにこのためで、[USB Implementers Forum](https://www.usb.org/documents)がその水準を定義するバッテリー充電仕様を公開しています。1Aのポートはこの枠組みでは標準レートのポートであり、それ以外を期待した消費者は、仕様ではなく体験を不具合として読み取ります。

ここではUSBポートは充電コントローラーの役割を担いません。確認すべき数字は、ターゲット顧客の機器が許容できる速度で充電するために1Aを超える電流を求めているかどうか、それだけです。答えが「いいえ」なら、USBバージョンは無償の利益です。答えが「はい」なら、通常バージョンを出荷し、充電は別の充電器で行ってもらいましょう。

もうひとつ意外に思われる点があります。**USBポートは1つでも2つでも価格は同じです。** 価格差はポートがあるかどうかにあり、いくつあるかにはありません。

| バージョン | 価格 |
|---|---|
| USBなしのトラベルプラグ | 1.50米ドル未満 |
| USBポート付きトラベルプラグ（1つまたは2つ） | 3.00米ドル |

## 1つのアダプターが置き換えるもの

トラベルプラグが前提にしている計算は単純です。英国、オーストラリア、ドイツ、米国を旅する顧客は、そうでなければ4つのACアダプター、把握しておくべき4つの認証、そして1つをホテルの部屋に置き忘れる4つの機会を抱えることになります。

トラベルプラグがあれば、必要なのはアダプター1つとプラグ規格1つです。顧客は米国規格のプラグを持つデバイスをそのまま使い、他のソケットに届くようトラベルプラグを足すだけです。

電源につながなければ何の役にも立たない製品に対して、小さな付属品が大きな仕事をしているわけです。アダプターが、安価な調達の影響が最初に現れ、最も痛い形で響く場所のひとつである理由でもあります。これは模造品を分解した後に[IPLメーカーについての不都合な真実](/blog/ugly-truth-ipl-manufacturers-energy-adapter-fda)で書いています。

## カートンと物流データ

この付属品をデバイスと一緒にコンテナに積むコストを計算するなら、入るかどうかを決めるのはこの表です。

| バージョン | 1カートンあたりの個数 | カートン重量 | カートン寸法 |
|---|---|---|---|
| 鉄ピン | 200 | 約20.5kg | 50×48×36.5cm |
| 銅ピン | 100 | 12〜15.5kg | 52×27×37.0cm |

鉄は1カートン200個なので、1カートンあたりの密度はおよそ2倍となり、同じ数量ならカートン数は約半分で済みます。運賃を計算に入れると、これは単価の差よりも大きな意味を持ちます。小売用の包装も作り替える場合は、[包装と物流のサービス](/services/packaging-logistics)がカートン設計と積載計画をカバーします。

## この部品の指定方法

3つの判断で足ります。

ピン材質を選びます。アダプターが開梱体験の一部となるプレミアムデバイスには銅、実用品として使う大量生産品には鉄です。USBポートがお客様にとって1.50米ドル分の利益に値するかどうかを決め、決める前に1Aという数字を顧客の機器と照らし合わせてください。そのうえで市場の構成比をお知らせください。トラベルプラグはまさにそれを受け止めるために存在しており、1つのブランドが5つの付属品SKUを持たずに[1つのデバイスライン](/products)を複数の国へ展開できる理由でもあります。
