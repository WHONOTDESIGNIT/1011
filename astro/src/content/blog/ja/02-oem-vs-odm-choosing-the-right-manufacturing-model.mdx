# OEMかODMか：光エステ脱毛器の製造モデルの選び方

近年、美容テック市場は急速に成長しており、光エステ脱毛器はその中でも最も競争の激しい消費者向け製品のひとつです。ブランドが市場参入する際、最初に決めるのは工場との付き合い方です。業界で最も一般的なモデルはOEMとODMの2つです。アルファベットは1文字違うだけですが、かかる費用、時間、リスクはまったく別物です。

当社iShineのチームはその両方に対応しています。Cyden、Costco、Haierといった国際的な名前は当社のODMクライアントであり、MandySkin、HappySkinといった成長中の美容ブランドも当社のカスタムソリューションを採用しています。以下では、実際に手がけたプロジェクトをもとに、両方の道筋をご紹介します。

## OEMとは

OEMはOriginal Equipment Manufacturerの略で、平たく言えば受託生産です。ブランドが設計を提供し、工場が生産能力を提供します。ブランドは仕様書、技術要件、完全な図面を工場に渡し、工場は機械を作ります。設計権、仕様、機能、性能はすべてブランド側に残ります。代償として開発コストは高く、一般的に6〜12か月の期間がかかります。その見返りとしてカスタマイズの余地が大きく、製品はブランドが思い描く通りのものに育て上げられます。

## ODMとは

ODMはOriginal Design Manufacturerの略で、設計を含む受託生産です。工場は既製の製品プラットフォームを持っており、市場の需要に基づいて新しい製品コンセプトを開発することもあります。ブランドは当社の既存プラットフォームの上でカスタマイズし、自社ブランドとして市場に出します。基本設計は工場側にあり、ブランドが変更できるのは外観デザイン、カラー、ロゴ、パッケージ、取扱説明書、付属品の組み合わせです。

ODMの最大の利点はスピードです。一般的に2〜9か月で市場投入でき、初期投資も少なくて済みます。さらに重要なのは、当社はブランドパートナーと設計権や知的財産を共有し、世界各地の特定地域向けのビジネス開発モデルを一緒に作り上げることを歓迎している点です。つまり、設計を一括で買い切る必要はなく、提携の過程で自社の製品モート（参入障壁）を少しずつ築いていけるのです。

## 両者を並べて比べる

| 項目 | OEM | ODM |
| --- | --- | --- |
| 設計の所有権 | ブランドが設計全体を所有 | 工場が基本設計を所有し、ブランドと共有可能 |
| IP（知的財産）の所有 | ブランド専有 | 交渉次第——共有または買い取り |
| 開発期間 | 6〜12か月 | 2〜9か月 |
| 開発費と型費の投資額 | 80,000〜250,000米ドル以上 | 30,000〜100,000米ドル |
| 最小発注数量 | 1,000〜5,000台 | 500〜5,000台 |
| カスタマイズの自由度 | フルカスタム | 設定済みのオプションに限定 |
| リスク | 高い——設計が未検証 | 低い——設計が検証済み |

2つの列を並べてみると、投資額の差が最も際立ちます。OEMの開発費と型費は80,000米ドルから始まり、上限はありません。ODMなら30,000〜100,000米ドルでスタートできます。

最小発注数量も異なります。ODMは500台から生産ラインを立ち上げられますが、OEMは一般的に1,000台からです。理由は複雑ではありません。OEMの型や生産ラインは製品専用に開かれるため、少量ではコストを分散できないのです。

## 型費とBOMコスト

ここでよくある誤解をひとつ解消しておきます。開発費と型費は、単価とは別物です。

型費は**一度きりの投資**です。IPLデバイスの筐体用に射出成形金型を1セット開くには、製品構造の複雑さ、金型のキャビティ数、求められる表面仕上げにもよりますが、一般的に**20,000〜50,000米ドル**かかります。

1台あたりのコストは**BOM（部品表）**で決まります。筐体、ランプカートリッジ、コンデンサ、回路基板、光学フィルター、ファン、電源アダプター——すべての部品の仕様と供給元が確定して初めて、正確な単価を算出できます。設計によって部品への要求は大きく異なり、攻めた設計では非標準部品が必要になり、コストが顕著に上がります。

現在、当社の単価は**20〜58米ドル**の範囲です。この幅の広さこそが理由です。標準プラットフォームは標準部品を使うためコストを抑えられます。カスタム設計は性能は高いものの、非標準部品を使うため高くなります。

開発費と型費は最初に必要なハードルであり、BOMの材料費は長期的な台帳です。両方の勘定がはっきりすれば、どのモデルが本当に自分に合っているのかがわかります。

## OEMを選ぶべきとき

OEMの前提条件は、具体的な製品アイデアを持っていること、市場に合う製品がないこと、あるいは誰も持っていない製品を作りたいことです。理由はいくつかの型に整理できます。革新性が明確であること。独自技術を搭載していること。競争に勝てるだけの差別化があること——他と同じような見た目では戦う武器がありません。あるいは、標準ソリューションでは通過できない特別な規制がターゲット市場にあること。こうしたクライアントは通常、成熟したチャネルと大量の発注量を持ち、製品ラインを長期的なビジネスと位置づけ、高価格帯を狙っています。これらの条件を多く満たすほど、設計と開発は自社で握るべきです。

MandySkinとの案件は典型的なOEMの事例です。彼らは敏感肌向けの光エステ脱毛器を求めており、要件は非常に具体的でした。肌刺激を抑えるカスタムフィルタリング、設計し直したハンドルのグリップ、独自の冷却システム、治療経過を記録するモバイルアプリ。この4つはいずれもパラメータ調整でごまかせるものではなく、設計段階から作り直す必要がありました。完成した製品は彼らのフラッグシップとなり、顧客満足度は標準的な光エステ脱毛器より40%高くなりました。

## ODMを選ぶべきとき

ODMを選ぶクライアントは、通常、現実的な目標を持っています。急いで市場参入したい人——2〜9か月の立ち上げ期間がぴったり合い、OEMの6〜12か月は待てない。社内に研究開発チームがなく、開発力に自信がない企業——同じく適合します。初期投資を最小限に抑え、予算をマーケティングとブランドに振り向けたいブランド。そしてもうひとつ、慎重なタイプ——既製製品でまず市場を試し、需要を検証してから、大型のカスタム開発に投資するかどうかを決めたい人たちです。

HappySkinはスタートアップの美容ブランドで、クラウドファンディングの期間が決まっており、製品を3か月以内に発売しなければなりませんでした。OEMではそのスケジュールに間に合わないため、当時顧客満足度95%を誇った当社の成熟プラットフォームから1台を選びました。外観とカラーリングを変更し、自社ブランドとパッケージデザインを加え、アプリのインターフェースを使い慣れたバージョンに差し替えました。10週間で発売にこぎつけ、クラウドファンディングの目標を300%上回って達成し、市場を掴みました。

ODMのプロジェクトでは、当社はブランドパートナーと設計権や知的財産を共有し、世界各地の特定地域向けのビジネス開発モデルを一緒に作り上げることを歓迎しています。ブランドはプロジェクト完了後に何も残らないのではなく、自社の製品モートを少しずつ築いていけるのです。

## ハイブリッドモデル

成熟したブランドの多くは3つ目の道を選びます。まずODMで参入し、基盤ができたらOEMに切り替える方法です。

フェーズ1：既製のODMソリューションで発売し、市場シェアを獲得します。その過程で顧客フィードバックと市場データを集め、ブランド認知とチャネルを構築し、売上からの収益で後の開発資金をまかないます。

フェーズ2：OEMに切り替え、市場フィードバックに基づいてカスタム機能を開発し、独自のセリングポイントを作り、独自技術を蓄積して、最終的に製品を高価格帯へ押し上げます。

## どのモデルでも省けないこと

まず技術仕様の数字を示します。

| パラメータ | 要件 |
| --- | --- |
| 波長範囲 | 590〜1200ナノメートル |
| エネルギー密度 | 1平方センチメートルあたり3〜6ジュール、強度調整可能 |
| パルス幅 | 1〜10ミリ秒、肌質や毛質に合わせて調整 |
| 冷却方式 | 接触冷却または空冷 |
| 安全構成 | 肌色センサー、UVフィルター、自動電源オフ |

認証ももうひとつの厳しい関門であり、工場を選ぶ前に確認すべきです。米国市場への参入にはFDAクリアランスが、欧州市場にはCEマークが必要で、現在は[MDR規制](https://eur-lex.europa.eu/eli/reg/2017/745/oj)——EU規則2017/745が2021年5月26日から義務化されています。FCC認証は電磁適合性をカバーします。ISO 13485は医療機器の品質マネジメントシステム、IEC 60601は医用電気機器の安全規格です——いずれも医療機器の要件に従います。工場がこれらの認証をひとつも取得できなければ、どれだけ見積もりが安くても手を出すべきではありません。

品質システムも事前に明確にしておく必要があります。入荷検査——すべての部品を仕様と照合して確認。組立中の重要パラメータの工程内監視。完成品の全数性能・安全試験。加速劣化とストレス試験による信頼性試験で長期的な挙動を確認。そして輸送中の破損がないことを確かめるパッケージ検証。この5つのステップをひとつでも省略すると、製品に跳ね返ってきます。

## 費用と時間、2つの台帳

まずOEM側です。

| 項目 | 金額 |
| --- | --- |
| 開発費 | 50,000〜200,000米ドル |
| 型費 | 20,000〜50,000米ドル |
| 単価（BOM＋製造費） | 20〜58米ドル（数量による） |
| 最小発注数量 | 1,000〜5,000台 |
| 損益分岐までの期間 | 一般的に12〜18か月 |

次にODM側です。

| 項目 | 金額 |
| --- | --- |
| カスタム開発・適合費 | 10,000〜50,000米ドル |
| 型費の償却 | 20,000〜50,000米ドル |
| 単価（BOM＋製造費） | 20〜58米ドル（仕様による） |
| 最小発注数量 | 500〜5,000台 |
| 損益分岐までの期間 | 一般的に6〜12か月 |

2つの台帳を並べると、傾向は明確です。OEMは初期に大きなお金がかかります——開発費と型費で80,000米ドルから始まり、損益分岐まで1年〜1年半。ODMはスタートがはるかに軽く、カスタム開発が10,000〜50,000米ドル、型費が20,000〜50,000米ドルなので、合計30,000〜100,000米ドルで始められ、損益分岐まで半年〜1年です。

単価は両モデルとも20〜58米ドルの範囲です。幅が広いのはBOMの違いによるものです。標準プラットフォームは標準部品を使うためコストを抑えられ、攻めた設計は非標準部品を必要とするため高くなります。ODMの単価が必ずしもOEMより高いわけではありません——具体的な構成次第です。

## 工場の選び方

当社が内部でパートナー工場を評価するときは、3つの領域を見ます。

1つ目は技術力です。研究開発チームが社内にあるか、IPLデバイス製造の経験があるか、試験・検証設備が十分に先進的か——これらが開発が実現するかどうかを直接左右します。美容デバイス製造の実績と、規制対応を処理できる能力は、工場の基礎体力を読み取る最も簡単な2つの指標です。

2つ目は製造力です。ISO認証を取得しているか、品質マネジメントシステムがどれだけ整っているか、生産能力の柔軟性、サプライチェーン管理能力——これらが納期通りに全量を出荷できるかを直接決めます。

3つ目は付き合い方です。プロジェクトのコミュニケーションと工程管理が透明か、協業モデルや商条件を柔軟に交渉できるか、長期的な関係を築く気があるのか、それとも1回きりの受注か、発売後のアフターサポートが追いつくか。

## 業界のゆくえ

ここ数年、IPL製造の変化はかなりはっきりと見えます。

| 方向性 | 現状 |
| --- | --- |
| スマート接続 | IoTとアプリ連携が標準に |
| パーソナライズ | AIが肌分析から治療プランを個別設計 |
| サステナビリティ | 環境配慮素材、省エネ設計 |
| 小型化 | 旅行向けのより小さく持ち運びやすいデバイス |
| 多機能化 | IPLと他の美容機能の組み合わせ |
| 安全性の強化 | より高度な肌色検知、リアルタイムモニタリング |

こうしたトレンドが次世代製品の姿を直接決めます。パートナー工場を選ぶ際は、これらの方向性に備えがあるかどうかをその場で確認しましょう。

## どう決めるか

判断基準は数行にまとまります。

OEMの条件はハードな要件です。製品が独自性を持つこと。100,000米ドル以上の開発投資を用意できること。発注量が1,000台以上に達し得ること。6〜12か月の開発サイクルを待てること。あなたにとって差別化が決定的であればあるほど、迷う必要はありません。

ODMは別のセットです。発売まで2〜9か月しかない、開発予算が限られている、検証済みの設計をそのまま使ってマーケティングとブランドに力を注ぎたい、技術リスクを自分で負いたくない——そういう場合です。そしてODMプロジェクトでは、工場はブランドと設計権・知的財産を共有し、世界各地の特定地域向けのビジネス開発モデルを一緒に作り上げることを歓迎します。つまり、設計を一括で買い切らなくても、提携期間中に自社の製品モートを少しずつ築いていけるのです。

長年この業界にいて、私の考えはシンプルです。急いでいて予算が限られているなら、まずODMで市場を取って、その過程でブランド資産と製品知識を積みましょう。独自のアイデアを持ち、お金も時間もあるなら、OEMがおすすめです。この2つの道は対立しません——ODMから始めて後からOEMに移行したクライアントを数多く見てきました。
