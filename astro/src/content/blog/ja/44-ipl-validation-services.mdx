# IPL認証サービス：最初の100台から月5,000台まで——コンプライアンスのはしごの登り方

IPL（強力パルス光）デバイスの販売を始めるのに、初日からMDR（EU医療機器規則）やFDA 510(k)のような高額な認証は必要ありません。月に数十台から数百台の規模で市場を試すのであれば、製品は通常の美容家電（コンシューマーエレクトロニクス）として扱われます。EUで合法的に販売するには、家電向けCE（低コスト・短期間）で十分です。高額な認証は、市場参入前に買わなければならない入場券ではなく、売上に応じて登っていくはしごなのです。

私はiShineの共同創業者兼CEOのEricです。過去15年にわたり、数百のブランドが最初の1台から月数万台規模まで成長するのを支援してきました。この記事は認証のリストではありません。**いつ**何が必要なのか——そして同じくらい重要な、まだ何が不要なのか——を整理したものです。

## コンプライアンスのはしご：全体像

| 販売段階 | 必要なもの | 理由 |
|---|---|---|
| **スタートアップ期（月1〜100台）** | 家電向けCE（LVD + EMC + IEC 62471光生物学的安全性） | 低コスト・短期間でコンプライアンスを満たして販売可能 |
| **成長期（月100〜3,000台）** | IEC 60335-1 + IEC 62471 + ISO 13485工場品質システム + 肌色センサーのバリデーション | 販路からより充実した品質エビデンスを求められる |
| **成熟期（月3,000〜5,000台）** | FDA 510(k)（米国）/ MDRに基づくCE（EU） | 規制当局の目が向き始め、税関の検査対象になることも |
| **スケール期（月5,000台以上）** | フルスタック認証 + 多国登録 + 市販後調査 | 市場の主要プレーヤーとして、完全なコンプライアンスが期待される |

ここで重要な原則は、**認証は販売数量に追従する**ということです。入場料ではなく、階段を一段ずつ上がっていくものなのです。

## 実例2つ：UlikeとCyDen

**Ulike**は、世界でも数少ない、MDRに基づくCE認証を実際に取得した家庭用IPLブランドです。これは完全な医療機器プロセスであり、数百万ユーロの費用、数年にわたる作業、認証機関（Notified Body）による本格的な監査を伴います。

**CyDen**——SmoothSkinの製造元——は今もMDRプロセスを進行中で、まだ証明書を保有していません。当社自身がEUDAMEDで確認し、[EU MDR深掘り解説](/blog/eu-mdr-home-ipl-devices)にまとめています。

この2つの事例が率直に示しているのは、**MDR CEは取得が極めて難しく、世界中でほんの一握りのブランドしか完走していない**ということです。あなたにとってより重要なのは、CyDenはMDR証明書を持つ前からEU市場で販売していた——しかも合法的に——という事実です。EUは医療機器以外のルートでの上市を認めており、すでに市場にある製品については移行期間が2028年末まで続きます。

ブランドオーナーであるあなたへの3つの学び：

1. **初日からMDRを目指さない。** 目的が市場のテスト、ブランド構築、販売数量の拡大なら、家電向けCEから始めるのが現実的な選択です。
2. **MDRはゴールであってスタート地点ではない。** 月3,000〜5,000台を動かすようになり、規制当局の関心が向き、税関が荷物の検査を始める——その時点でMDRまたはFDA 510(k)のプロセスを始めればよいのです。間に合わないということはありません。
3. **コンプライアンス予算は収益とともに増える。** 初期は数千ユーロの試験費用があれば十分です。月5,000台の段階なら、収益が支えるので7桁（数百万ユーロ規模）の認証予算を組めます。

## ステージ1：スタートアップ期（月1〜100台）——通常の美容家電として

必要なもの：**家電向けCEのみ**。

- **LVD（低電圧指令）**——基本的な電気安全
- **EMC（電磁両立性）**——他の機器に干渉しないこと
- **IEC 62471光生物学的安全性試験**——光出力が肌と目に無害であること

費用：数千ユーロ。リードタイム：数週間。

この段階では、IPLデバイスは「医療機器」ではなく「美容家電」に分類されます。製品コピーでは「トリートメント」「医療グレード」「治療」といった表現は使えません。「家庭用美容機器」「脱毛器」「スキンケアツール」であれば使用可能です。大多数の新興ブランドがこの合法的なルートから始めています——EU全域で数千台のIPLデバイスが、まさにこの方法で、月数十台から数千台の規模で販売されているのです。

## ステージ2：成長期（月100〜3,000台）——品質システムのアップグレード

売上が安定し、販路（小売店、マーケットプレイス）からより充実した品質エビデンスを求められるようになったら、次の段階へ進みます：

| 追加要件 | 理由 |
|---|---|
| **IEC 60335-1のフル試験** | 基本的なLVDよりも厳格な電気安全 |
| **IEC 60601-1-2（医療機器グレードのEMC）** | 電磁両立性を医療機器規格の水準に引き上げ |
| **ISO 13485工場品質システム** | 製造元が医療機器の品質システムを運用していることの証明 |
| **肌色センサーのバリデーションデータ** | さまざまな肌色に対して安全であることを販路に示す |

これはまだMDRではありません——MDRへ*向かう*道です。これらの書類は販路に受け入れられ、「小さな販売者」から「信頼できるブランド」への格上げを可能にします。

## ステージ3：成熟期（月3,000〜5,000台）——FDA 510(k)またはMDRを始める

月3,000台を超えると、**規制当局の目があなたに向き始めます**：

- 各国当局（ドイツのBfArM、フランスのANSM）が分類の正しさを審査する可能性がある
- 税関が荷物を検査し、完全な技術文書を要求する可能性がある
- 競合他社があなたのコンプライアンス状況を当局に報告する可能性がある

本格的なデバイスレベルの認証に着手するのは、この時点です：

| 市場 | 認証 | 費用／期間 |
|---|---|---|
| **米国** | FDA 510(k)クリアランス | 数万〜数十万米ドル、6〜18ヶ月 |
| **EU** | MDRに基づくCE（認証機関による監査） | 数十万ユーロ、2〜4年 |
| **その他** | TGA（オーストラリア）、Health Canada、MOHAP（湾岸地域） | ケースバイケースだが、通常はFDAまたはCEを土台にする |

このステージは本物の関門です。臨床評価、リスクマネジメント（ISO 14971）、生体適合性（ISO 10993）、そして長期間にわたる技術文書の維持管理が必要になります。Ulikeのようなごく一部のブランドしか完走していないのは、本当にそれだけ難しいからです。

## 実践的な判断フレームワーク

過去5年間の美容ブランドの実例に基づく指針です：

| 対象市場 | 開始時の段階 | デバイスレベル認証の開始時期 |
|---|---|---|
| **EU（非医療ポジショニング）** | 家電向けCE + IEC 62471 | 月3,000台超、または販路から要求された時点 |
| **EU（医療ポジショニング）** | 家電向けCE + IEC 62471 | 月1,000台前後までにMDRの道を開始（リードタイムが長い） |
| **米国** | 美容機器として参入——複雑なのでFDAコンプライアンスアドバイザーに相談 | 通常は月500〜1,000台になる前にFDA 510(k)を開始 |
| **湾岸（UAE／サウジアラビア）** | MOHAP登録（延期可能） | 通常は月1,000台以降 |
| **オーストラリア／カナダ** | 遅めの開始で可 | 通常は月1,000〜3,000台の段階 |

ブランドから絶えず寄せられる質問があります。家電として参入し、後でMDRやFDAにアップグレードした場合、それまでの販売が遡って問題にされるのでしょうか？販売時点で適用されていたルール（家電向けCE）を守っていた限り、医療ポジショニングに切り替える際に製品コピーと書類を更新すれば、一般的には遡及適用されません。執行の裁量は市場によって異なるため、ルートを切り替える際は現地のコンプライアンスアドバイザーに確認してください。

## バリデーションの基盤レイヤー：すべてのステージで必須

どの段階にいても、一定のバリデーションは常に必要です。規制が要求するからではなく、製品安全の基本保証だからです：

1. **IEC 60335-1電気安全**——感電、過熱、発火がないこと
2. **IEC 62471光生物学的安全性**——光出力が肌と目に無害であること
3. **IEC 60601-1-2電磁両立性**——相互に干渉しないこと
4. **ランプ寿命試験データ**——宣伝するフラッシュ回数が検証されていること
5. **肌色センサーのバリデーションデータ**——肌色センサーを謳うなら、機能することを証明する
6. **ISO 13485工場品質システム**——デバイス証明書ではなく、製造元に品質システムがあることの証明

これらの合計費用は数千〜数万ユーロで、MDRやFDA 510(k)の6〜7桁（数十万〜数百万ユーロ）のコストとは比べものになりません。これらこそ、どの段階でも工場に要求すべき「最低限受け入れ可能な書類」です。

（具体的なIEC規格と、よくある混同——IEC 61511がIPLに*適用されない*理由を含む——については、[IPLコンプライアンス規格](/blog/ipl-compliance-iec-standards)をご覧ください。）

## 家電向けCEとMDR CEの比較

| | 家電向けCE | MDR CE |
|---|---|---|
| **対象** | 一般家電、美容機器 | 医療機器 |
| **試験規格** | LVD + EMC + IEC 62471 | IEC 60601-2-57 + ISO 14971 + 臨床評価 + 認証機関による監査 |
| **費用** | 数千ユーロ | 数十万ユーロ以上 |
| **期間** | 数週間 | 2〜4年 |
| **認証機関（Notified Body）** | 不要 | 必須 |
| **「トリートメント」を謳えるか** | 不可 | 可 |

## 工場が提示できるべきもの——どの段階でも

信頼できるIPL工場——当社も含めて——に足を運び、これらを要求してください。これらの書類を備えているパートナーは、ためらわずに提示します：

1. 認定試験所（TÜV、SGS、Intertek、BSIなど）による**IEC 60335-1試験報告書**
2. **IEC 62471試験報告書**——光生物学的安全性
3. **ISO 13485認証書**——期限切れでない有効なもの
4. **ランプ寿命試験データ**——定格フラッシュ回数がどのように測定されたか
5. **肌色センサーのバリデーションデータ**（センサー搭載機の場合）——Fitzpatrick肌タイプ別のエネルギー低減カーブ

「パートナーが持っている」「後で送ります」という回答があれば、それが答えです。認証は秘密ではなく、公開記録です。市場登録レイヤー（FDA 510(k)、MDR、TGA、MOHAP）については、対象市場に適用されるものを確認してください。米国のクリアランスは、工場と一致する会社名で[FDA公開データベース](https://www.accessdata.fda.gov/scripts/cdrh/cfdocs/cfPMN/pmn.cfm)から検索できます。

## ブランドオーナーへの最終アドバイス

1. **シンプルに始める。** 市場を試し、ブランドを育てたいなら、家電向けCEで数週間・数千ユーロのうちにコンプライアンスを満たして販売を始められます。
2. **認証を成長のはしごと捉える。** 最初からMDRやFDAを追いかけないこと。コンプライアンス投資は売上が引っ張ります——月3,000〜5,000台を動かすようになり、規制当局が注目し、税関が検査するようになった時こそ、大きな認証に着手する時です。
3. **工場に基盤バリデーション書類を要求する。** MDRがなくても、IEC 60335-1、IEC 62471、ISO 13485は必要です。これらは製品安全と工場の信頼性の最低基準です。
4. **コンプライアンスの経路とマーケティング上の主張を分ける。** 箱に「CE」と印刷することはできます（家電向けCE）。ただし「医療グレード」や「トリートメント」は不可です。医療ポジショニングを目指すなら、時間と費用の予算を組みましょう。
5. **工場に正直に話す。** 実際の販売段階を伝えてください。優れた工場は、まだ必要のない認証を売りつけるのではなく、あなたの現状に合ったコンプライアンス経路を提案します。

**契約前にメーカーに確認すべき3つの質問：**

1. 認証：最低限のバリデーション書類一式（IEC 60335-1、IEC 62471、ISO 13485）は何か。価格交渉の前に提示してもらえるか？
2. MOQと価格：数量に応じた価格ブレーク（50台／500台／1000台）はどうなっているか。量産前にサンプルとブランディングから始められるか？
3. サプライチェーン：これらの試験を実施した工場そのものか、それとも別工場の検証済み設計を転売しているのか？

当社は多くの家庭用IPLブランドの背後にある工場です——15年以上の実績、50万台以上の出荷実績を持ち、FDA 510(k)、ISO 13485、MDRの技術文書（MDRプロセス中のクライアント向け）、湾岸向けのMOHAPを含む市場別の登録書類を備えています。ブランドの成長段階によって必要なコンプライアンス支援は異なります——このはしごの趣旨はまさにそこにあります。

## FAQ

### 最初からFDAやMDRは本当に必要ないのでしょうか？

その通りです。対象市場がEUで「美容機器」としてポジショニングするなら、家電向けCE（LVD + EMC + IEC 62471）で十分です。FDAとMDRは医療グレードのデバイス向けの認証経路であり、コストは100倍以上です。

### 製品コピーには何を書けますか？

「家庭用IPL脱毛器」「美容ツール」「家庭用美容機器」といった表現は可能です。「トリートメント」「医療グレード」「治療」「治癒」は使えません——これらの言葉はデバイスを医療機器の規制枠組みに引き込んでしまいます。

### 月100台売ったら規制当局に狙われるのでしょうか？

ほぼありません。EUと米国の規制当局はリソースが限られており、高ボリュームのブランドと輸入業者に焦点を当てています。月3,000〜5,000台あたりから、ようやく当局の視界に入り始めます。

### 家電向けCEとMDR CEの違いは何ですか？

家電向けCEは一般家電と美容機器を対象とし、LVD + EMC + IEC 62471が必要で、費用は数千ユーロ、期間は数週間、「トリートメント」と謳うことはできません。MDR CEは医療機器向けです。IEC 60601-2-57 + ISO 14971 + 臨床評価 + 認証機関による監査が必要で、数十万ユーロ、2〜4年かかり、医療ポジショニングを謳うことができます。

### FDAやMDRを考え始めるべきタイミングはいつですか？

次のいずれかに該当する時です：月間販売台数が3,000台を超える、販路（小売店、マーケットプレイス）から要求される、税関が荷物の検査を始める、「医療グレード」や「臨床的に有効」と謳う予定がある、規制当局から問い合わせを受ける。

### UlikeとCyDenのMDR事例から何が学べますか？

Ulikeは、実際のMDR証明書を持つ世界でも数少ない家庭用IPLブランドです。SmoothSkinの製造元であるCyDenは、今もプロセスを進行中です。両事例はMDRの取得が並外れて難しいことを示しています——それでもCyDenは証明書を持つ前から、医療機器以外のルートと移行期間を活用してEUで合法的に販売していました。ほとんどのブランドは現実的に市場参入し、数量が正当化する段階でアップグレードしていくのです。

### ブランドオーナーとして負う責任は何ですか？

どの経路を選んでも、製品安全に対する最終責任はあなたにあります。工場から受け取った試験報告書が本物であることを確認し、製品コピーを実際のコンプライアンス状況と一致させ、規制当局の検査に備えて適合書類を保管し、対象市場でアフターセールスとクレーム対応の体制を整えてください。
