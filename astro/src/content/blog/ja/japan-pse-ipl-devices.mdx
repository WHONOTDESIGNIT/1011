**短い答え：** Japanで販売される家庭用IPL機器には、電気用品安全法に基づくPSEマークが必要です。家庭用IPLが2つの区分のどちらに入るかは、Japanの実務では確定していません。ほとんどの機器は丸形マークの非特定電気用品として、少数は菱形マークの特定電気用品として扱われます。書類は工場が用意します。Japanのインポーターが届出を行い、法的責任を負います。

## Japanが「サンプルを送って結果を見る」市場ではない理由

多くの市場では、ブランドは適合対応の費用を出す前に需要を試せます。Japanはほとんどそういうふうには動きません。マークは最初の販売個体が出る前に製品とパッケージに載り、届出はJapanに存在する法人に紐づきます。

ですから順序は、新しいブランドが期待する流れとは逆になります。まずインポーターを探します。インポーターが、その機器をどの区分で扱うつもりかを教えてくれます。区分が試験の根拠を決めます。試験の根拠が表示を決めます。パッケージを印刷するのは、そのあとです。

この順序を間違えると、表示版を刷り直すことになります。

## 分類の問題を、率直に述べる

法律は電気用品を2つのグループに分けています。特定電気用品は菱形のマークを付け、登録機関による適合性検査が必要です。非特定電気用品は丸形のマークを付け、試験報告に裏づけられた自己宣言が認められます。

成熟した製品分野では、この振り分けは調べれば済む話です。家庭用IPLではそうなりません。この分野はまだ新しく、試験所、インポーター、コンサルタントの読み方が分かれ、全員が従う線を公表した単一の当局もありません。実際には、市場はおおよその型に落ち着いています。家庭用IPL機器の大多数は非特定電気用品として扱われ、少数が特定電気用品として扱われます。

これは抜け道ではありません。製品分野がガイダンスより速く到来したときに起きることです。

| | 丸形PSE（非特定） | 菱形PSE（特定） |
|---|---|---|
| 誰が評価するか | 事業者（試験報告に裏づけられる） | 登録適合性検査機関 |
| 保持する証拠 | 試験報告と試験結果の証明 | 検査機関が発行する証明書 |
| 工場が用意するもの | 技術資料、試験報告、表示版 | 技術資料、サンプル、試験報告 |
| 家庭用IPLでの実際の割合 | 一般的なルート | 少数派のルート |
| Japan国外の工場が届出を持てるか | いいえ | いいえ |
| 発売日程への影響 | インポーターの社内審査に左右される | 検査機関の待ち行列に左右される |

インポーターがどちらのルートを取るにせよ、パッケージの発注前に書面にしておきます。どちらを使うつもりか、その理由を述べられないなら、その案件は印刷できる段階にありません。印刷後にルートを知ったブランドは、版代を2回払います。

## VENUSプラットフォームについて当社が保有しているもの

買い手が実際に聞いてくる質問なので、助言ではなく当社自身の立場を書きます。

VENUSプラットフォームは丸形ルートで扱われています。エミッションについてJ55014-1で試験しており、これは家電機器に適用されるJapanの要求です。また、皮膚または毛髪の手入れ用機器の安全性についてIEC 60335-2-23で試験しており、これはIPL機器が皮膚に触れる部分を対象とする規格です。試験結果の証明は2025年に発行され、報告書は保管しています。

当社が保有しておらず、主張もしないのは、VENUSの菱形マーク証明書です。販売代理店が菱形ルートが必要だと言ってきたら、正直な答えはこうです。それは別の日程を持つ別の案件であり、引き出しから出せる書類ではありません。

どのサプライヤーにも、同じ形でこの質問をしてください。どのルートか、どの規格に裏づけられているか、いつ発行されたか、そして報告書を見せてもらえるか。「PSEは取っています」とだけ答えてルートを言わないサプライヤーは、答えていません。

## 誰が、誰の名で届け出るのか

Japanの市場に製品を置く事業者が、METIの地方局への届出を行います。輸入機器の場合、それはインポーターであり、工場ではありません。

そこから3つの帰結が出て、それが人を驚かせます。

- 表示に載るのはインポーターの名称と住所であり、工場のものではありません。ブランド自身がJapanの法人でない限り、ブランドのものでもありません。
- インポーターが当局の連絡先になります。製品に関するあらゆる質問は、まずそこに届きます。
- インポーターは検査記録を提示できなければならず、その記録管理は、工場が何を送るか、そしてそれが提出できる形式で届くかどうかにかかっています。

したがってJapanの法人を持たないブランドは、商標を保有していても責任主体ではありません。Japanのインポーターが最初の1年で優位に立つのは、これが構造的な理由です。

## インポーターが工場に求めるもの

毎回同じ6つの書類が出てきます。案件ごとにではなく、1つのパックとして一度にまとめておきます。

| 書類 | インポーターが必要とする詳細 | よくある不足 |
|---|---|---|
| 試験報告 | どの規格、どの試験所、どの型番、発行日 | 報告書が、輸入するものとは別のバリエーションを対象にしている |
| 技術資料 | 構造、定格、部品表、回路情報 | 部品表が部品を商標名だけで示し、定格がない |
| 定格と表示版 | 電圧、周波数、電力、マークの位置 | インポーターの身元が決まる前に作られた版 |
| 検査記録 | 日常検査の項目と結果、保存できる形式 | 記録が、インポーターに提出できない形式で保管されている |
| トレーサビリティ | ロットまたはシリアルの符号、およびその表示箇所 | 符号がまったくなく、リコールの範囲を決められない |
| 証明と委任 | 誰が何を、誰のために宣言するか | 証明が、届出事業者ではない者によって署名されている |

最後の行が、最も多くの手戻りを生みます。届出がインポーターにある場合、工場が署名した証明は、インポーターが保管すべき書類と噛み合いません。解決策は、最初に合意しておく1ページの書類一覧です。どの書類を、誰が発行し、誰が保持するのか。

## 表示に載せなければならないもの

```
PSE mark:          <circle or diamond, per the route agreed in writing>
Business operator: <importer name>, <address>, <phone>
Manufacturer:      <factory legal entity, country>
Model:             <model code used in the test reports>
Rating:            <V, Hz, W>
```

型番の行は、見た目以上に重要です。Japanのインポーターは表示と試験報告を照合し、箱の符号と報告書の符号が一致しないと、税関ではなくインポーターの社内審査で落ちます。1つの符号を合意し、すべての書類でそれを使います。

## これが日程にとって何を意味するか

Japanでの適合対応は順番に進み、インポーターとの関係ができた後に始まります。

1. インポーターを特定し、ルートを書面で合意します。
2. 試験報告を取得するか、適用規格に対して確認します。
3. インポーターが届出を行います。
4. インポーターの情報で表示版を更新し、そのうえで印刷します。
5. 初回生産。検査記録はインポーターの書類に合う形式にします。

工場が動かせるのは手順2と4で、発売を最も頻繁に遅らせるのもこの2つです。インポーターの身元が決まる前に表示版は確定できず、試験後に機器を変更したなら報告書は流用できません。

## 当社がやること、やらないこと

当社は、技術資料、適用規格に対する試験報告、定格と表示版、検査記録、トレーサビリティの符号を作成します。届出は行いませんし、インポーターの役も務めません。また、求められれば原本の報告書を示せないPSEマークや証明番号は、このサイトのどのページにも載せません。

Japanでの発売を検討しているなら、[プライベートラベル（OEM）の進め方](/services/private-label)に、どの段階でどの書類が出るかを示しています。JapanをEUや米国と同時に比べる人には、[市場ごとに規制ルートがどう違うか](/blog/how-regulators-classify-home-ipl)が併読に向いています。また、[世界の規制概観](/blog/08-global-regulatory-landscape-for-ipl-devices)は、どの市場が証明書で止まり、どの市場が届出で止まるかの地図です。機器そのものについては、[VENUSプラットフォーム](/products/venus)がこの記事で扱っている機種です。
