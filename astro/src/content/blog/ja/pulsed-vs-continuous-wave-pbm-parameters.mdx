**短い答え：**連続波（CW）は途切れない光子の流れを届け、パルス波（PW）は同じエネルギーを断続的なバーストとして届けます。この違いによって、周波数・パルス幅・デューティ比・ピーク電力が用量に加わります。そしてエネルギーを揃えた実験では、それらの追加パラメータが細胞の応答を両方向に動かしてきました。パルス波PBMは、多くの人がすでに測っている軸の隣に、用量の第二の軸として並びます。

実験台の上に2台の装置があります。どちらも808 nmで発光します。どちらも10 J/cm²として仕様に書かれています。筐体には同じ電力値が印字されています。同じ細胞株に同じ照射時間で使ってみても、ATPの測定値は一致しません。

パルス化の話は特殊なものではありません。IPLはintense pulsed lightの略であり、このサイトの生産ラインで作られる脱毛器はすべて、光をどのようにバーストへ分割するかという決定にすでに依存しています。そして、その決定の裏にあるパラメータが仕様表に載ることはほとんどありません。この光がどのように作用することを想定しているのかについては、消費者向けの解説を[IPL脱毛とは実際に何か](/blog/what-is-ipl)でご覧ください。

その一行の用量記述の中には、どちらに転ぶかを予測するものは何もありません。その記述はそもそも完全ではなかったからです。フルエンスは、単位面積あたりどれだけのエネルギーが届いたかを示します。そのエネルギーが連続的な流れとして届いたのか、バーストの列として届いたのかについては何も語りませんし、そのバーストがどのように形作られたかについても何も語りません。

## 光がパルスに分割されると実際に何が変わるのか

CWでは、発光素子が施術の間ずっと点灯しています。PWでは、決められた周期で点灯と消灯を切り替えるため、4つの新しいパラメータが仕様に加わります。

| パラメータ | 何を決めるか |
|---|---|
| 周波数 | 1秒あたりに発生するパルス数 |
| パルス幅 | 個々のパルスが持続する時間 |
| デューティ比 | 各周期のうち発光素子が実際に点灯している割合 |
| ピーク電力 | パルスが点灯している間の瞬間的な電力 |
| 平均電力 | 消灯時間を含めた周期全体で平均した電力 |

パルスがほぼ矩形であれば、平均電力とピーク電力は次の関係にあります。

**平均電力 ≈ ピーク電力 × デューティ比**

ピーク100 mWでデューティ比10%なら平均は10 mWです。10 mWで連続動作する発光素子も平均は10 mWです。データシート上の数字は同じでも、組織に与える刺激はまったく別物です。

その算術こそが、「100 mW」という記載だけではパルス波のプロトコルを記述できない理由です。2台の装置が同じ数字を印刷していても、実際のピーク電力は1桁違うことがあります。一方は穏やかな連続のフルエンス率を届け、もう一方は短く強いバーストを暗い間隔で区切って届けますが、平均値はそれを隠してしまいます。私たちは、消費者向けIPL脱毛器をパワーメーターに載せてラベルが実際に何を届けているかを測ったとき、同じ報告の欠落に反対側から突き当たりました：[28ジュールはどこから来るのか](/blog/the-truth-about-ipl-energy)。

## パルス化は「冷たい」という意味ではない

パルス化を支持する直感的な論拠は熱です。パルス化は間隔を生み、間隔は熱を拡散させ、拡散は温度上昇を抑えます。この推論はその範囲では妥当ですが、そのまま押し進めると成り立たない主張に滑り込みます。

パルス化は発熱がないことではありません。光生体調節（PBM）は通常、非熱的あるいは低熱的と説明されますが、その説明は意図された領域についてのものであって、組織についての保証ではありません。吸収された光子は熱になり、その結果生じる温度上昇は、平均電力、デューティ比、パルス幅、総照射時間、スポット面積、そしてその組織固有の熱的性質に依存します。脱毛器にサファイア接触冷却が存在するのはまさにこの理由であり、箱に書かれたフラッシュ回数よりも冷却スタックのほうが重要である理由でもあります：[サファイア氷感冷却が実際にしていること](/blog/cooling-ipl-hair-remover-buying-guide)。

より良い定式化はこうです。光子の供給の時間分布を変えると、熱の蓄積の仕方が変わる。これは検証可能な主張です。「パルス光は熱くならない」は検証可能ではありませんし、照射時間の長い高ピーク電力のパルスプロトコルは、控えめなCWプロトコルよりも多くの熱を蓄積し得ます。

## 周波数は細胞データに現れる

もしパルス化の役割が熱管理だけなら、これは熱工学の話題であって、それ以上ではありません。細胞実験は別の方向を指しています。

Kimらは、ヒト歯髄幹細胞において、連続810 nmと、いくつかの周波数のパルス810 nmを比較しました。彼らの研究条件では周波数が影響しました。異なるパルス周波数は異なる生体エネルギー応答を生み、パルス群は連続を単純に増幅したのではなく、そこから分岐しました。彼らの300 Hz群では、活性酸素種および他のいくつかの生物学的マーカーにおいて、より顕著な変化が現れました。

持ち帰る価値のある結果はこれです。エネルギーをほぼ一定に保ったまま、パルス周波数を変えると、生物学的応答が測定可能な形で変わりました。これは、周波数をPBMのパラメータ集合の中で、波長やフルエンスの後ろに隠れた装置設定としてではなく、それらと並ぶ独立変数の候補として位置づけます。

## デューティ比：平均電力は揃うが、瞬間は揃わない

これが最も頻繁に見落とされるパラメータです。

2つのプロトコルを考えます。どちらも平均10 mWです。プロトコルAは10 mWの連続です。プロトコルBはピーク100 mWでデューティ比10%です。平均電力として報告すれば両者は同一です。しかし刺激の瞬間には何も共有していません。プロトコルBは同じエネルギーを短い高振幅の窓に集中させ、その後は暗転します。

Tangらは、神経芽細胞腫細胞に対して660 nmと850 nmの赤色光および近赤外光を、さまざまなパルス周波数とデューティ比で、連続照射と比較して検討しました。細胞生存率、ATP、活性酸素種、ミトコンドリア膜電位はすべてパルス周波数に対する感受性を示し、周波数を固定したままデューティ比を変えると、それらのマーカーはさらに動きました。

これは解釈上の制約として読むべきです。ある論文が「850 nm、10 mW/cm²」と報告しているとき、次に問うべきは、その数字が連続の放射照度なのか、パルス列全体の平均なのかです。平均であれば、ピーク電力、周波数、デューティ比、パルス幅がなければその結果は再現できません。必要な数字は1つではなく4つです。

## 高いピーク電力は深い到達を買わない

論理の連鎖はこうです。パルス化はピーク電力を上げ、電力が高いほど光は強く、光が強いほど深くまで届き、したがってパルス波PBMはより深い組織を治療する。どの段階ももっともらしく聞こえます。しかし連鎖は2番目の環で切れます。

組織内での光の伝搬は、使用する波長における吸収と散乱、経路上の組織の組成、ビームの形状によって決まります。同じ総エネルギーをより短いバーストで届けると、表面での瞬間電力は上がりますが、その下にあるものの光学特性は変わりません。ピーク電力は到達深度の代理指標にはなりません。到達深度を実際に動かす変数は波長です。510–1200 nmの窓と610–1200 nmの窓の違いが体裁の問題ではないのはそのためです：[波長域が毛包に届くものをどう変えるか](/blog/ipl-hair-removal-wavelength-range)。

Andoらは、マウスの外傷性脳損傷モデルで、連続810 nmと、10 Hzおよび100 Hzのパルス810 nmを比較し、すべての群で平均電力密度、照射時間、エネルギー密度を揃えました。10 Hzパルス群は、いくつかの神経学的・組織学的指標でより良い結果を示しました。注目すべきは、その改善を説明するのに到達深度の話が必要なかったことです。平均電力密度が揃っている以上、パルス群が単純な意味でより多くの光を組織に届けていたわけではありません。時間構造の何かが応答を変えたのです。

## 連続波が勝つ場合

これは、パルス化に焦点を当てた要約から抜け落ちる部分です。

Khalajらは、ヒト歯肉線維芽細胞において近赤外のCWとパルス近赤外を比較し、特定の5.2 J/cm²の条件で、細胞増殖と遊走に対して連続波のほうが有効であると報告しました。これは彼らのパラメータにおけるin vitroの結果です。同時に、パルス波が連続波を上回るという一律の主張に対する、直接の反例でもあります。

Keshriらは、皮膚創傷を持つ免疫抑制ラットを用いて、特定のパルス810 nmパラメータが比較群に対して創傷治癒の転帰を改善することを見出しました。線維芽細胞の結果と併せて考えると、正直な要約はこうなります。文献には、ある調製ではパルス波が勝ち、別の調製では連続波が勝つ。

## 同じ波長がなぜ異なる答えを出し続けるのか

PBMのパラメータ依存性は、数ある治療モダリティの中でも際立っています。1つの変数を入れ替えると、結果が反転し得ます。808 nmに固定しても、放射照度（低いか高いか）、照射時間、エネルギー密度、モード、パルス周波数、デューティ比を変えられます。総エネルギーを揃えても、10 Jを連続で届けるのと、10 Jをパルス列として届けるのは同じ刺激ではありません。

これは、光生体調節の文献が用量そのものについて記録してきたのと同じ二相性の挙動（[Huang et al., 2009](https://pubmed.ncbi.nlm.nih.gov/20011653/)）を、一段深く拡張したものです。二相性用量反応は、エネルギーが多ければ単調に良いわけではないと言います。パルス化の文献はさらに、エネルギー供給の*スケジュール*も情報を運ぶと付け加えます。

まとめると、用量は少なくとも2つの層が重なったものです。

- 空間的・能量的な層：波長、スポット径、放射照度、フルエンス
- 時間的な層：周波数、パルス幅、デューティ比、ピーク電力、平均電力、照射時間

## 完全なPBMパラメータ集合とはどのようなものか

2つの研究や2つの装置を比較するなら、比較が意味を持つ前に、最低限一致していなければならない項目がこれです。

| パラメータ | なぜ必要か |
|---|---|
| 波長 | 吸収と散乱の挙動を決める |
| 出力電力 | 下流のすべての基準になる |
| 放射照度 | 表面でのフルエンス率を決める |
| フルエンス | 単位面積あたりの総エネルギー |
| スポット径 | ビームの形状と照射される面積 |
| 周波数 | パルス化している場合の1秒あたりのパルス数 |
| デューティ比 | パルス化している場合の、各周期で発光素子が点灯している割合 |
| パルス幅 | パルス化している場合の、単一パルスの持続時間 |
| 照射時間 | 1回のセッションの長さ |
| セッション | 施術の回数と間隔 |

パルス波の装置では、平均電力だけを報告するのが最もよくある失敗です。読み手はピーク電力とデューティ比から平均電力を計算できますが、その逆はできません。ピーク電力、周波数、デューティ比がなければ、そのプロトコルは再現できず、結果をメカニズムに帰属させることもできません。その等式の組織側も装置側と同じくらい変動するため、同じパラメータでもFitzpatrickタイプや部位によって結果が変わります：[肌タイプ別のIPL副作用](/blog/ipl-side-effects-by-skin-type)。

## これをどう使うか

PBM装置を比較するなら、まず電力値を仕様として扱うのをやめることから始めてください。それがピークなのか平均なのかを尋ねてください。次に時間パラメータを求め、その不在を細部ではなく欠落として扱ってください。同じ規律は消費者向け脱毛器にも当てはまります。そこでは仕様表が、施術の体感を実際に決める光学的・熱的な設計ではなく、フラッシュ回数を宣伝する傾向があります：[フラッシュ回数よりもコーティングが重要な理由](/blog/why-premium-ipl-devices-feel-different)、そして、パンフレットで説明されるのではなく7つが並べて試験されたときに、実験室で測定されたフィルタースタックがどのような姿になるか：[ロングパスフィルター試験レポート](/blog/ipl-long-pass-filter-test-report)。

研究を読むなら、時間の層が報告されているかを確認してください。808 nmと10 J/cm²だけを書いた方法のセクションは、用量のおよそ半分しか記述していません。

実験を行うなら、両方の層を報告してください。ある装置が家庭で使って安全かどうかを判断する人は、まさにこれらのパラメータで判断しています。この議論の消費者向けの版が私たちの安全性ピラーにあるのはそのためです：[IPL脱毛は安全か](/ipl-hair-removal-is-safe)。

同じ波長は同じ施術ではありません。同じ総エネルギーは同じ刺激ではありません。結果を決める変数には、エネルギーがいつ届いたか、そして届くまでにどのように形作られたかが含まれます。当社が製造する各プラットフォームでそれらの変数がどう規定されているかを見たい場合は、[製品ラインナップ](/products)に各モデルのフルエンス、スポット径、パルス設定が載っています。
