# IPL脱毛器の開発にはどのくらいかかる？当社のタイムライン：253日・14段階

あるブランドが、店頭の何にも似ていない機器を持って当社を訪れました。8か月後、認証を取得し量産準備が整ったIPL脱毛器をお渡ししました。253日。14段階です。

当社はiShineです。ブランド企業のお客様に向けてフルプロセス開発を行っています。ブランドがコンセプトを渡せば、当社は認証済みの製品と、それを製造できるラインをお返しします。そのコンセプトの多くは標準のハンド型スティックではありません。混み合う店頭で目立つように設計されたデスクトップ型、ガン型ハンドル、その他の家庭用IPLの形状です。

この記事では、実際のデスクトップ型IPLプロジェクトを例に、時間が正確にどこへ行くのかを示します。日数は暦日です。

**IPL脱毛器の開発にはどのくらいかかりますか？** キックオフから量産まで8～9か月を見込んでください。当社の直近のフルプロセスプロジェクトは14段階で253日かかりました。認証は約4か月で、単一の段階としては最長です。

## フルプロセス開発が実際に意味すること

ブランドは通常、スケッチと頭の中の市場だけを持ってやって来ます。信頼できる日付はありません。

フルプロセス開発とは、その引き渡しから量産までのすべてを当社が所有するということです。構造、ハードウェア、ソフトウェア、金型、認証、試作生産。ブランドは決められたゲートでレビューし、スケジュールは当社が担います。

その所有権こそが、定量化されたタイムラインを可能にします。ブランドが5社のサプライヤーを縫い合わせれば、その間の隙間は誰も所有しません。当社はチェーン全体を所有するので、プロジェクト開始前にすべての段階に日付を付けられます。

## フォームファクターがスケジュールを左右する理由

標準のハンド型IPLスティックは解決済みの製品です。筐体も熱予算も既知の値であり、だからこそどの商品ページも同じに見えるのです。

目立ちたいブランドには、異なる形状が必要です。より広い照射窓とより高い出力を持つデスクトップ型。難しい角度でも持ちやすいガン型ハンドル。スティックではないあらゆるフォームファクターは、想定ではなく再検証が必要な、新しい構造・新しい冷却・新しい安全マージンを強制します。

その再検証こそが、新しいコンセプトの本当のコストです。出荷済みの熱設計をコピーすることはできません。もう一度証明するのです。良いスケジュールは、それが無料であるふりをするのではなく、そのための余地をあらかじめ確保します。

## IPL脱毛器の開発タイムライン、段階ごとに

デスクトップ型プロジェクトで実際に運用したスケジュールです。

| 段階 | 期間 | 何があったか |
|---|---|---|
| 予備技術仕様 | 5～7日 | プロジェクト前。コンセプトを何よりも先に定義 |
| R&D実現可能性レビュー | 4日 | 技術調査、初期安全リスク |
| 技術提案と推奨 | 4日 | 提案、スケジュール、タスク定義 |
| 仕様改訂 | 3日 | 設計インプットを確定 |
| 商用見積 | 3～5日 | 技術作業と並行して進行 |
| 最終技術合意 | 3日 | 設計インプットを凍結 |
| プロジェクトキックオフ | 6日 | チーム結成、計画レビュー |
| プロトタイプ開発 | 59日 | 構造、ハードウェア、ソフトウェア、グラフィック |
| EVT | 8日 | DMRマイルストーンまでのソフトウェアデバッグ |
| DVT | 13日 | 設計アウトプットを発行 |

キックオフから量産までの総エンジニアリング時間：約253日、つまり8.3か月。プリセールス段階まで数えるなら、およそ2週間を加えてください。

## 253日は実際にどこへ行くのか

タイムラインの大半は2か所にあります。

認証は124日かかりました。プロトタイプ開発は59日。標準の段階リストには決して現れない金型が、さらに31日かかりました。残りのすべて — キックオフ、EVT、DVT、ゴールデンサンプル、PVT、生産ランプアップ — は残り39日に収まります。

もう一度読んでください。プロジェクトのほぼ半分が認証であり、寿命試験を待つために遅れて始まります。

## 最長の段階は認証：124日

どのブランドに、新しい美容機器で何が怖いか尋ねても、同じ答えが返ってきます。認証です。

このプロジェクトでは124日かかりました。その期間の中で：

- 性能・輸送梱包・ソフトウェア試験は1月8日までに完了する必要がありました。
- 寿命試験（信頼性試験）は1月29日まで終わりませんでした。
- 第三者による検査・試験は5月1日に締め切りました。

1月29日から5月1日までの区間が、スケジュールが死ぬ場所です。その大半はエンジニアリングではなく、外部ラボを待つ時間です。設計インプットの段階で認証機関を予約していなければ、その数か月が量産を顧客のローンチ日より先へ押し出していたでしょう。

**IPL機器の認証にはどのくらいかかりますか？** 4か月を見積もり、ラボを早めに予約してください。寿命試験だけで数週間かかり、第三者の報告書はそれが終わって初めて開始できます。

## 金型：リストにない段階

金型が段階リストから抜けていることにお気づきでしょう。ほとんどのタイムラインで見えませんが、スケジュールはそれを織り込んでいました。DVT（11月20日）とゴールデンサンプル（12月21日）の間には、31日の金型製作がありました。

金型は古典的な隠れた依存関係です。金型がなければ、ゴールデンサンプルはありません。ゴールデンサンプルがなければ、認証サンプルもありません。このプロジェクトでは金型が試作実行を縛り、試作実行が認証サンプルを縛りました。

## 大半のブランドが間違えること

当社の経験では、4つあります。

第一に、認証の予算を過小に見積もります。チームはPCBと筐体を日単位で計画し、最後に「認証：3週間」と走り書きします。3週間だったことは一度もありません。4か月であり、時計は寿命試験が終わって初めて動き始めます。

第二に、順序を逆にします。多くのブランドは、ゴールデンサンプルを造る前に認証すると思い込みます。このプロジェクトは逆に進みました。ゴールデンサンプルとPVTは12月21～25日、認証は12月28日から5月1日まで。認証には実物のサンプルが必要なので、先に造るのです。

第三に、仕様を途中で変えます。プロトタイプ段階（59日）は、キックオフ後にコンセプトがぶれるたびに膨らみます。初日に凍結された仕様は、後日の残業よりも価値があります。

第四に、金型が存在することを忘れます。金型は設計ができた日に発注されるのではありません。4～5週間のリードタイムであり、クリティカルパスの真ん中に座っています。

## もっと速くできますか？

はい、2か所で。

プロトタイプ段階は、顧客が初日に仕様を凍結すれば圧縮されます。その時間の一部は設計作業ではなく、仕様が途中でぶれた後の修正でした。

認証は、必要になる前にラボを予約して初めて短くなります。寿命試験にエンジニアリングの近道はありません。
