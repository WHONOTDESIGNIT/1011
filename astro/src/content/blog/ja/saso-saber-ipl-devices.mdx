**短い答え：**Saudi Arabiaが発行する適合証明書は1通ではありません。SABERは、有効期間が約1年の製品証明書と、船積みごとの船積み証明書を発行します。2025年以降、船積み証明書は貨物が港に到着する前に手元になければならず、この期限は試験の不合格よりも多くの負担を輸入業者に強いてきました。

## SABERは認証機関ではなくプラットフォームです

SABERが製品を認証しているかのように、この名前は使われます。実際には認証していません。SABERは2種類の異なる文書を発行するためのオンラインシステムであり、その2つの違いこそが計画を狂わせる場所です。

| | 製品適合証明書（PCoC） | 船積み適合証明書（SCoC） |
|---|---|---|
| 対象 | 製品そのもの、期間は約1年 | 船積み1回分 |
| 再利用 | 可、複数の船積みで使える | 不可、船積みごとに必要 |
| 前提 | 試験エビデンスと技術ファイル | 有効な製品証明書と船積書類 |
| 発行主体 | SABER（輸入業者または認定機関） | SABER（船積みごと） |
| 失効 | 固有の有効期限による | 実質的には到着時 |

「SASO証明書」を前提に計画するメーカーは、たいてい最初の列だけを計画に入れ、2列目を忘れます。期限があるのは2列目のほうです。

## 到着ルール

2025年以降、船積み証明書は貨物がSaudiの港に到着する前に発行されていなければなりません。到着後に申請された証明書は無効とみなされ、貨物は通関できません。

これによって計画の形が変わりました。以前は、船が海上にあるうちに船積み証明書の手続きを始め、コンテナが動き出す前に終えることができました。今は順序が逆転しています——証明書が先、到着が後です。決まったスケジュールで出荷する工場にとっては、書類を予約の後にではなく前に揃えておく必要があるということです。

実務上の帰結は2つあります。

- 製品証明書が遅れても、遅れるのは製品証明書そのものではありません。有効な参照がなければ何も証明できないため、遅れるのは**今後すべての船積み**です。
- 航空貨物は猶予を広げるのではなく、狭めます。輸送が5日しかないと、書類の欠落に気づく余地がありません。

## CBレポートで得られるもの、得られないもの

有効なCB証明書とレポートは、一部の製品では試験の根拠として受け入れられます。これが数週間と数か月の差になります。ただし、Saudi向けファイルの代わりにはなりません。

電源駆動の美容家電では、毎回2つの国別要求が問題になります。

- **プラグ。**Saudiのプラグは独自の規格に従っており、CBレポートに何が書かれていても、箱に入っている欧州仕様のプラグは適合しません。これは書類の変更ではなく、製品の変更です。
- **電源。**220 V、60 Hzです。50 Hzのみに対応した定格のアダプターは仕様上の問題であり、その定格は表示から読み取れなければなりません。

つまりCBレポートが短縮するのは試験であり、ハードウェア側の論点はそのまま残ります。買い手がCB証明書を関門そのものと受け取ることがあるため、これは率直に書いておく価値があります。

## Arabic表記と、何が基準になるか

ラベルと取扱説明書にはArabicを含める必要があります。2言語併記は受け入れられ、Arabicのみである必要はありません。重要なのは、Arabicが製品本体と取扱説明書に載っていることであり、輸入業者の倉庫で追加される別刷りの紙ではないということです。

IPLデバイスでは、警告と禁忌が載る取扱説明書にリスクが集まります。規制市場での文言は翻訳の練習問題ではなく、英語版マニュアルを字面どおりに訳したものは、SABERが関与する前に輸入業者側のレビューで却下されることがよくあります。

## タイムライン、段階ごとに

以下はSABERが公表しているサービス基準に、その周辺で実際に起きることを加えたものです。数字は保証ではなく、計画用の目安として扱ってください。

| 段階 | 標準的な期間 | 決め手 |
|---|---|---|
| CBレポートの移行（利用できる場合） | 2〜4週間 | レポートが出荷構成と一致するかどうか |
| 新規試験（利用できない場合） | 4〜8週間 | 要求される規格の範囲 |
| 製品証明書の登録 | 公表値で約8日 | 技術ファイルの完成度 |
| 船積み証明書 | 公表値で約3日 | PCoC参照番号、インボイス、パッキングリスト、船荷証券 |
| 初回出荷までの合計 | 3〜6週間 | 主に試験の段階 |

最初のコンテナがいつ出せるのかと尋ねる顧客には、一番下の行を見せてください。

## 誰が何を持つのか

実際にSABERを運用するのはSaudiの輸入業者、または輸出者のために動く認定適合機関です。つまりこの市場は、このシリーズで同じ構造的な論点を持つ5番目の市場になります——域内にいる主体が関門なのです。

EUには責任者が、英国には輸入業者が、日本にはMETIへの届出を行う輸入業者が、オーストラリアにはスポンサーがいます。ユーラシア経済連合は居住者である申請者を要求し、Saudi ArabiaはSABERを操作できる主体を要求します。名前は違えど、形は同じです。

したがって、Saudi拠点を持たないブランドにとって、輸入業者は物流上の些事ではありません。その主体こそ文書を発行できる当事者であり、その関係が出荷の速さを決めます。

## 当社が提供するもの

| 項目 | 内容 |
|---|---|
| 技術ファイル | 構造、定格、部品リスト、製品写真 |
| 試験エビデンス | 認定規格に基づくレポート、CB証明書が引き継げる形式で |
| アダプターとプラグ | Saudiプラグ、電源定格を製品に表示 |
| ラベル原稿 | Arabicと英語、輸入業者の欄は現地の主体向けに空けておく |
| 取扱説明書 | Arabicと英語、警告は市場向けにレビュー済み |
| 一貫性 | レポート、ラベル、カートンで1つの型番に統一 |

最後の行は、輸入業者が証明書とカートンを突き合わせるまでは些細なことに聞こえます。そして実際に、彼らは突き合わせます。

## 当社が行うこと、行わないこと

当社は技術ファイル、試験エビデンス、Saudiプラグとアダプターの構成、2言語のラベルと取扱説明書の原稿、そして書類の一貫性を保つ型番マトリクスを作成します。SABERの操作は行わず、製品証明書や船積み証明書の発行も行わず、CBレポートだけを根拠に機器をSASO認証済みと称することもありません。
