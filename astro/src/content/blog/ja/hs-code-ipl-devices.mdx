**短い答え：** 家庭用IPLデバイスは、少なくとも2つの関税コード、8510.30と8543.70で取引に現れます。どちらの項（heading）も、この製品を想定して書かれたものではないからです。コードは関税、特恵待遇、報告を決め、最終的な判断は記録上の通関業者が下します。購入者が譲れないとすべきなのは、その出荷のあらゆる書類がそのコードと一致していることです。

## 2つの項、そして両方が出てくる理由

1つ目の項はシェーバー、ヘアクリッパー、脱毛器具を対象としており、その条文自体が自蔵電動機を前提としています。シェーバーにはそれが当てはまります。IPLデバイスにはモーターが一切ありません。キセノンランプ、コンデンサバンク、制御基板、冷却システムです。

その不一致こそが、同じ取引で残余項が出てくる理由です。個別の機能を有し、他の項に明記も含まれもしていない電気機械および器具。関税率表が想定していなかった製品の、正直な収容先です。

どちらのコードも実際の書類に現れます。グラデーションハウジング504台のある注文では、輸出申告書が脱毛器具のコードを、製品ページが同じ番号をUSコードとして記載し、2通目のパッキングリストが残余項のコードを記載していました。書類2通、出荷1件、答えは2つです。

この製品カテゴリでは、そのこと自体は珍しくありません。珍しいのは、申告の後ではなく前にそれを見つけることです。

## なぜコードは書類の細部ではないのか

関税は3つの要素の関数です。コード、原産地、そしてその原産地が適用できる制度です。1つを変えれば、着地原価の数字が動きます。

| コードが影響するもの | その理由 |
|---|---|
| 関税率 | 項が違えば税率も違い、その差は運賃より大きいことがよくあります |
| 特恵待遇 | 自由貿易協定は項ごとに交渉されます |
| 追加関税プログラム | 原産地に基づく措置は製品の説明ではなく項単位で適用されます |
| 輸入許可と基準 | 一部の仕向地は特定の項に市場監視や登録を結びつけています |
| 統計報告と割当 | 輸入者自身の報告はコード単位で提出されます |

つまりコードの問いは、事務処理の整理整頓ではありません。計算された着地原価と、推測された着地原価の違いです。

## 実際に決めるのは誰か

記録上の通関業者（ブローカー・オブ・レコード）が申告し、その申告書に署名するのはその業者です。これは迂回すべき形式ではありません。ブローカーが、自分では防御できないコードの使用を拒む理由がここにあります。

購入者には次の3点が導かれます。

- **注文を出す前に、コードを書面で求めること。** 貨物が船出した後の商業送り状で求めるのではありません。
- **どの関税率表に対して確認したのかを聞くこと。** USの関税率表で正しいコードが、原産国での輸出申告にも自動的に正しいわけではありません。これは2つの別の関税表であり、食い違っていて構わないのです。
- **モデルが変わったらどうなるかを聞くこと。** 回転ヘッド用にモーターを追加し、LED版のためにランプを外せば、項もそれに合わせて動き得ます。

3点すべてに答えるサプライヤーは、これを以前に経験しています。「いつも同じコードを使っています」と言うサプライヤーは、監査を受けたことがないと告げているのです。

## 一貫性のルール

出荷を止めるのはこの部分であり、そして完全に工場の制御下にあります。**商業送り状、パッキングリスト、原産地証明書、申告書のすべてが同じコードを記載し、貨物がその背後の説明と一致していなければなりません。**

送り状が一方の項を、申告書がもう一方の項を示す出荷は、国境での不整合です。どちらが正しかったかは問題になりません。

もう半分は説明です。「脱毛装置」という申告上の説明は、一方の項には無理なく収まり、もう一方の項にはぎこちなく収まります。説明とコードは一緒に選ばなければなりません。

## 私たちの注文で行っていること

私たちはコードを商業書類に記載し、ブローカーが提出する前に申告書と突き合わせます。504台のあの注文の不整合が、港で発見されるのではなく見つかったのはそのためです。製品ページにも同じコードを使うので、サイトを読む購入者と送り状を読むブローカーは同じ番号を見ています。

私たちがしないのは、顧客の輸入関税がいくらになるかを告げることです。その答えは顧客の関税率表、原産地規則、そして顧客自身のブローカーの見解に依存し、輸入申告に署名する当事者は私たちではないからです。

## 最初の出荷の前に聞くこと

1. 商業送り状に載るのはどのコードで、どの関税率表に対して確認したのか。
2. そのコードは、まさにこのモデルの過去の出荷で使われ、照会なしに通関したのか。
3. モデルが変わった場合、誰が、いつ、コードを再確認するのか。
4. 提出前に、送り状、パッキングリスト、原産地証明書、申告書を互いに突き合わせられるか。

4つの問い、1ページの答え、注文と一緒に保管。分類変更より安くつきます。

出荷先の市場に独自の適合性制度がある場合、コードは輸入書類の半分にすぎません。[規制当局が家庭用IPLデバイスをどう分類するか](/blog/how-regulators-classify-home-ipl)は製品側を扱い、[梱包と物流のプロセス](/services/packaging-logistics)は書類がどのように一緒に運ばれるかを扱っています。関係の工場側については、[OEM/ODMのプロセス](/services/oem-odm)が、関税とコードの問いがプロジェクトの流れの中でどこで解決されるかを示します。
