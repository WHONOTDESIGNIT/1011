**คำตอบสั้น ๆ:** ใบโปรฟอร์มาอินวอยซ์คือเอกสารที่ทีมการเงินของผู้ซื้ออ่านก่อนที่เงินจะเคลื่อน มันต้องระบุเงื่อนไขทางการค้าเดียวกันกับใบเสนอราคา มี Incoterm พร้อมชื่อสถานที่ และกระทบยอดจำนวนเครื่องกับจำนวนกล่องให้ตรงกัน ช่องที่ผิดพลาดคือช่องเดิม ๆ ในทุกโปรเจกต์

## ทำไม PI ถึงสำคัญกว่าใบเสนอราคา

ใบเสนอราคาเปิดบทสนทนา ใบโปรฟอร์มาอินวอยซ์คือสิ่งที่ฝ่ายการเงินของผู้ซื้อใช้ยื่นขอชำระเงิน จองสกุลเงิน และเปิดเลตเตอร์ออฟเครดิตถ้ามีสักฉบับ

นั่นเปลี่ยนมาตรฐาน ใบเสนอราคาจะประมาณการไว้ก็ยังมีประโยชน์ได้ PI ที่มีช่องใดช่องหนึ่งเป็นค่าประมาณจะกลายเป็นคำถามเรื่องการชำระเงิน จากนั้นเป็นอีเมลคุยกันหลายรอบ จากนั้นเป็นเงินมัดจำที่ล่าช้า

มีสี่สิ่งที่ต้องเป็นจริงก่อน PI จะออกไปได้:

- ตรงกับใบเสนอราคาในเรื่องราคา เงื่อนไข และขอบเขตงาน
- ทุกจำนวนกระทบยอดกัน: จำนวนเครื่อง จำนวนกล่อง จำนวนต่อกล่อง
- Incoterm มีชื่อสถานที่กำกับ ไม่ใช่แค่รหัสสามตัวอักษร
- เงื่อนไขทางการค้าที่มีผลต่อการเคลม โดยเฉพาะการรับประกัน ปรากฏอยู่บนเอกสาร

## รายการช่อง

| ช่อง | สิ่งที่ต้องระบุ | สิ่งที่ผิดพลาด |
|---|---|---|
| คู่สัญญา | ชื่อนิติบุคคลและที่อยู่ของทั้งสองฝ่าย | ใช้ชื่อทางการค้าฝ่ายเดียว ไม่มีนิติบุคคล |
| หมายเลขและวันที่ | เลขที่อ้างอิงของ PI และวันที่ออก | ไม่มีเลขที่อ้างอิง จึงไม่มีใครจับคู่กับการชำระเงินได้ |
| ระยะเวลามีผล | ราคายังมีผลอยู่นานเท่าไร | ปลายเปิด แล้วปรับราคาใหม่หลังผู้ซื้อตั้งงบแล้ว |
| สินค้า | รุ่น คำบรรยาย รหัสพิกัด | มีแต่คำบรรยาย ไม่มีรหัสรุ่น |
| จำนวน | จำนวนเครื่อง และจำนวนกล่องพร้อมจำนวนต่อกล่อง | มีแต่จำนวนเครื่อง ผู้รับจัดการขนส่งจึงไม่มีจำนวนกล่อง |
| ราคา | ราคาต่อหน่วย สกุลเงิน ยอดรวม | สกุลเงินต้องเดาจากบริบท |
| Incoterm | เงื่อนไข **และ** ชื่อสถานที่ | "FOB" ที่ไม่มีท่าเรือ |
| การชำระเงิน | เปอร์เซ็นต์เงินมัดจำ เงื่อนไขการจ่ายยอดคงเหลือ | "30/70" โดยไม่บอกว่า 70 เปอร์เซ็นต์ของอะไร หรือเมื่อไร |
| ระยะเวลาดำเนินการ | นับเป็นวันจากเหตุการณ์ใด | "25 วัน" จากจุดเริ่มต้นที่ไม่ได้ระบุ |
| การบรรจุ | จำนวนกล่อง ขนาด น้ำหนักรวมและน้ำหนักสุทธิ | ปล่อยให้เป็นหน้าที่ของใบรายการบรรจุสินค้าที่ยังไม่มีอยู่ |
| การรับประกัน | ระยะเวลา แยกตามแพลตฟอร์ม | มีอยู่ในแคตตาล็อก แต่ไม่มีที่นี่ |
| ข้อมูลธนาคาร | เลขบัญชี SWIFT ชื่อผู้รับประโยชน์ที่ตรงกับผู้ขาย | ชื่อผู้รับประโยชน์ต่างจากที่อยู่ในใบแจ้งหนี้ |

## สามช่องที่ทำให้คำสั่งซื้อหยุด

**Incoterm ที่ไม่มีสถานที่** "FOB" คือเงื่อนไขครึ่งเดียว FOB Shenzhen กับ FOB Ningbo เป็นราคาที่ต่างกัน และผู้ซื้อคำนวณต้นทุนถึงปลายทางไม่ได้ถ้าไม่มีท่าเรือ หลักเดียวกันใช้กับ DDP: สถานที่คือที่อยู่จัดส่ง และมันเปลี่ยนราคามากกว่าตัวเงื่อนไขเสียอีก

**กล่องที่ไม่กระทบยอดกับจำนวนเครื่อง** คำสั่งซื้อ 504 เครื่อง ที่ 18 เครื่องต่อกล่อง คือ 28 กล่อง ถ้า PI ระบุ 504 เครื่อง และใบรายการบรรจุสินค้าภายหลังระบุ 26 กล่อง จะมีคนต้องอธิบายส่วนต่างก่อนจองตู้คอนเทนเนอร์ และคำตอบมักเป็นเครื่องสำรองที่ไม่มีใครลงไว้ ให้ใส่บรรทัดเครื่องสำรองไว้บน PI

**เงื่อนไขการรับประกันที่ไม่เคยมาถึง** ใบเสนอราคาที่พูดถึงสองปี กับ PI ที่ไม่พูดถึงอะไรเลย ทำให้การรับประกันหลุดออกจากสัญญา เมื่อมีการเคลมสิบแปดเดือนต่อมา ผู้ซื้อหยิบใบเสนอราคาออกมา และซัพพลายเออร์หยิบ PI ออกมา

## เงื่อนไขการชำระเงินที่เขียนแล้วอ่านผิดไม่ได้

"30/70" เป็นคำย่อที่พอดีในหนึ่งประโยคและก่อให้เกิดการเถียงกัน ให้เขียนเป็นข้อเท็จจริงสามข้อ:

- เปอร์เซ็นต์เงินมัดจำและสกุลเงิน และอะไรเป็นตัวกระตุ้น: การลงนามใน PI หรือใบสั่งซื้อ
- เปอร์เซ็นต์ยอดคงเหลือและเงื่อนไขการจ่าย: ก่อนการจัดส่ง เทียบกับสำเนาใบตราส่งสินค้า หรือเมื่อสินค้าถึง
- ใครจ่ายค่าธรรมเนียมธนาคาร และจ่ายที่ปลายทางใด

เงื่อนไขการจ่ายสำคัญกว่าตัวเปอร์เซ็นต์ ยอดคงเหลือ 70 เปอร์เซ็นต์แบบ "ก่อนการจัดส่ง" เป็นดีลที่ต่างจาก 70 เปอร์เซ็นต์แบบ "เทียบกับเอกสาร" และทั้งสองแบบถูกเขียนว่า 70 เปอร์เซ็นต์ในอีเมลส่วนใหญ่

## รหัสพิกัดอยู่ตรงไหน

รหัสพิกัดต้องอยู่บน PI แม้ว่านายหน้าศุลกากรจะเป็นผู้สำแดง เพราะทีมการเงินของผู้ซื้อต้องใช้มันประมาณอากร และนายหน้าศุลกากรของผู้ซื้อต้องใช้มันก่อนสินค้าจะเคลื่อน

มันยังปกป้องคุณด้วย PI ที่มีรหัสและคำบรรยายที่สอดคล้องกับรหัสนั้นถูกจัดประเภทใหม่ภายหลังได้ยากกว่า ถ้ารหัสยังไม่นิ่ง ให้เขียนรหัสที่คุณตั้งใจจะสำแดงและกำกับว่าเป็นไปตามการยืนยันของนายหน้า แทนที่จะปล่อยช่องนั้นว่าง

## สิ่งที่เราลงบน PI ของเรา

เราออก PI พร้อมชื่อนิติบุคคล เลขที่อ้างอิงและระยะเวลามีผล รุ่นและรหัสพิกัด จำนวนเครื่องและจำนวนกล่องพร้อมบรรทัดเครื่องสำรอง Incoterm และชื่อสถานที่ สัดส่วนการชำระเงินพร้อมเงื่อนไขการจ่าย ระยะเวลาดำเนินการที่นับจากการรับเงินมัดจำ ข้อมูลการบรรจุ เงื่อนไขการรับประกันแยกตามแพลตฟอร์ม และข้อมูลธนาคารที่ชื่อผู้รับประโยชน์ตรงกับผู้ขาย

สิ่งที่เราไม่ทำคือการออก PI จากใบเสนอราคาที่ยังไม่ได้ตกลงกัน หรือปล่อยให้ PI ออกไปทั้งที่มีช่องที่ใบเสนอราคายังเปิดอยู่
