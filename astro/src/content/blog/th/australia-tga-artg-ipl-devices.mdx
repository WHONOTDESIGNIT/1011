**คำตอบแบบสั้น:** อุปกรณ์ IPL สำหรับกำจัดขนที่จำหน่ายใน Australia ถือเป็นเครื่องมือแพทย์ ต้องมีรายการใน ARTG ก่อนขายเครื่องแรก คำขอยื่นโดยผู้สนับสนุนชาวออสเตรเลีย ไม่ใช่โดยโรงงาน และหลักฐานที่ทำให้ผ่านการพิจารณามาจากโรงงาน Australia มักเป็นตลาดที่ช้าที่สุดในบรรดาตลาดหลัก และความสัมพันธ์กับผู้สนับสนุนคือเหตุผล

## คำถามเรื่องการจัดประเภทต้องมาก่อน และไม่ใช่เรื่องที่ข้ามได้

TGA ถือว่าอุปกรณ์ intense pulsed light สำหรับกำจัดขนเป็นเครื่องมือแพทย์ ในชั้นที่ต้องมีหลักฐานการประเมินความสอดคล้อง ไม่ใช่การรับรองโดยผู้ผลิตเอง ในทางปฏิบัติหมายถึง Class IIa

ชั้นของอุปกรณ์มีความสำคัญเพราะเป็นตัวกำหนดว่าผู้สนับสนุนยื่นอะไรได้ อุปกรณ์ที่อยู่ในชั้นต่ำกว่าชั้นที่ต้องประเมินสามารถขึ้นทะเบียนด้วยคำประกาศของผู้ผลิตได้ แต่ IPL ไม่ใช่เช่นนั้น

ยืนยันการจัดประเภทของอุปกรณ์รุ่นของคุณกับผู้สนับสนุนก่อนจะสร้างชุดเอกสารโดยยึดการจัดประเภทนั้น การจัดประเภทเป็นไปตามวัตถุประสงค์การใช้งานและคำกล่าวอ้าง และรายการที่สัญญาว่าจะลดขนอย่างถาวรถึงระดับรากผมนั้นถูกอ่านต่างจากรายการที่วางตำแหน่งเป็นเครื่องใช้ดูแลร่างกาย ใน EU ความต่างนี้เปลี่ยนเส้นทางที่ใช้ ใน Australia ความต่างนี้อาจเปลี่ยนชั้นของอุปกรณ์

## ผู้สนับสนุนคือฝ่ายที่แบกความรับผิดทางกฎหมายจริง

ผู้ผลิตต่างประเทศไม่สามารถถือรายการใน ARTG ได้ รายการนั้นเป็นของผู้สนับสนุนชาวออสเตรเลีย ซึ่งต้องรับผิดชอบทางกฎหมายต่ออุปกรณ์ใน Australia ตลอดเวลาที่อุปกรณ์อยู่ในทะเบียน

ประโยคเดียวนี้อธิบายความยุ่งยากเกือบทั้งหมด และมีสี่สิ่งตามมา

- **ชื่อของผู้สนับสนุนปรากฏบนฉลาก** เคียงคู่กับชื่อผู้ผลิต ไม่ใช่ชื่อแบรนด์ เว้นแต่แบรนด์นั้นเป็นนิติบุคคลในออสเตรเลีย
- **ผู้สนับสนุนเป็นผู้ยื่นและเป็นเจ้าของคำขอ** โรงงานเป็นผู้จัดหาหลักฐาน ไม่ใช่ผู้ยื่น
- **เหตุการณ์ไม่พึงประสงค์ถูกส่งถึงผู้สนับสนุนก่อน** พวกเขามีหน้าที่รายงานภายในกำหนดเวลาที่ไม่รอคำตอบจากโรงงาน
- **ผู้สนับสนุนแบกค่าธรรมเนียมรายปี** สำหรับการดูแลรายการให้อยู่ในทะเบียน ซึ่งเป็นเหตุผลที่ผู้สนับสนุนกำหนดเงื่อนไขทางการค้าโดยอิงปริมาณ

แบรนด์ที่ไม่มีนิติบุคคลในออสเตรเลียจึงต้องมีผู้สนับสนุนก่อนสิ่งอื่นใด ตำแหน่งเชิงโครงสร้างเดียวกับผู้รับผิดชอบใน EU แต่มีภาระทางกฎหมายหนักกว่า

## สี่คำถามที่กำหนดกรอบเวลา

ทุกโครงการออสเตรเลียที่ผมเคยเห็นต้องเจอจุดตัดสินใจสี่จุดเดียวกันนี้ ลำดับมีความสำคัญ เพราะแต่ละจุดเป็นประตูของจุดถัดไป

**หนึ่ง: ผู้สนับสนุนจะใช้เส้นทางการประเมินความสอดคล้องแบบใด?** TGA รับหลักฐานที่ผลิตมาด้วยวิธีต่างกันได้ สามวิธีที่พบบ่อยที่สุดสำหรับ IPL คือ:

| เส้นทาง | ผู้สนับสนุนยื่นอะไร | ผลในทางปฏิบัติ |
|---|---|---|
| การประเมินความสอดคล้องโดย TGA | คำขอต่อ TGA พร้อม technical file ฉบับเต็ม เพื่อให้ TGA ออกใบรับรอง | ช้าที่สุด ควบคุมได้มากที่สุด และ TGA ตรวจตามมาตรฐานของตนเอง |
| ใบรับรอง MDSAP | ใบรับรอง MDSAP ที่ยังใช้ได้ซึ่งครอบคลุมสถานที่ผลิตและขอบเขต | เร็วที่สุดหากโรงงานมีใบรับรองนี้อยู่แล้วในขอบเขตที่ถูกต้อง |
| ใบรับรองจาก notified body ในยุโรป | ใบรับรองที่ยังใช้ได้จาก notified body ใน EU พร้อมเอกสารทางเทคนิคที่รองรับ | ขึ้นกับว่าขอบเขตของใบรับรองตรงกับอุปกรณ์หรือไม่เท่านั้น |

เส้นทางถูกเลือกโดยฝ่ายที่ถือหลักฐาน โรงงานที่มีใบรับรอง MDSAP ครอบคลุมขอบเขตของอุปกรณ์จะย่นระยะเวลาโครงการได้หลายเดือน โรงงานที่ไม่มีใบรับรองนี้จะดันให้ผู้สนับสนุนไปทางการประเมินโดย TGA ซึ่งเป็นเส้นทางยาว

**สอง: ขอบเขตของใบรับรองครอบคลุมอุปกรณ์นี้จริงหรือไม่?** นี่คือจุดที่โครงการออสเตรเลียตายเงียบ ๆ ใบรับรองที่ครอบคลุมสถานที่ผลิตสำหรับตระกูลสินค้าหนึ่งไม่ได้ครอบคลุมรุ่นใหม่โดยอัตโนมัติ และผู้สนับสนุนไม่มีดุลพินิจที่จะขยายความให้ ตรวจถ้อยคำของขอบเขตก่อนสร้างแผนบนพื้นฐานนั้น

**สาม: ผู้สนับสนุนคาดหวังหลักฐานด้านสมรรถนะและหลักฐานทางคลินิกอะไร?** IPL เป็นอุปกรณ์ที่กล่าวอ้างเรื่องการลดขน ชุดเอกสารจึงต้องมีหลักฐานรองรับคำกล่าวอ้างนั้น ไม่ใช่แค่ความปลอดภัยทางไฟฟ้า ทั้งรายงานการทดสอบที่พิสูจน์ว่าอุปกรณ์ปล่อยพลังงานได้ตามที่ระบุในข้อกำหนด และข้อมูลที่รองรับการลดขนตามที่กล่าวอ้าง ต้องอยู่ในชุดเอกสารทั้งคู่ แพ็กที่มีแต่ข้อมูลความปลอดภัยจะถูกส่งคืน

**สี่: ฉลากและ IFU ต้องระบุอะไร?** ชื่อและที่อยู่ของผู้สนับสนุน ข้อกำหนดของออสเตรเลียสำหรับคำแนะนำในการใช้ และคำเตือนที่มาพร้อมวัตถุประสงค์การใช้งาน IFU เป็นส่วนหนึ่งของผลิตภัณฑ์ที่ถูกกำกับดูแล ไม่ใช่รายละเอียดของงานพิมพ์

## สิ่งที่ผู้สนับสนุนขอจากโรงงาน

| เอกสาร | รายละเอียด | จุดที่โครงการเสียเวลา |
|---|---|---|
| Technical file | ข้อมูลการออกแบบ โครงสร้าง ชิ้นส่วน และซอฟต์แวร์ | เขียนมาเพื่อ CE และขาดเหตุผลรองรับด้านสมรรถนะที่ TGA คาดหวัง |
| รายงานการทดสอบ | ความปลอดภัยและ EMC ตามมาตรฐานที่ระบุในชุดเอกสาร | รายงานครอบคลุมอุปกรณ์เวอร์ชันก่อนหน้า |
| หลักฐานด้านสมรรถนะ | ผลวัดเอาต์พุตเทียบกับข้อกำหนดที่กล่าวอ้าง | คำกล่าวอ้างใน IFU กว้างกว่าข้อมูลที่รองรับ |
| เอกสารการบริหารความเสี่ยง | ตาม ISO 14971 โดยอันตรายผูกกับดีไซน์จริง | เป็นเทมเพลตทั่วไป ไม่สามารถสอบกลับถึงอุปกรณ์นี้ได้ |
| ฉลากและ IFU | ร่างอาร์ตเวิร์ก รวมถึงบล็อกข้อมูลผู้สนับสนุน | ร่างไว้ก่อนระบุตัวผู้สนับสนุน |
| หลักฐานการผลิต | ใบรับรองสถานที่ผลิต ขอบเขต และประวัติการตรวจประเมิน | ขอบเขตใบรับรองไม่ระบุชื่อตระกูลสินค้า |
| ข้อมูลหลังการจำหน่าย | บันทึกข้อร้องเรียนและการคืนสินค้า หากอุปกรณ์เคยขายที่อื่น | ไม่มีบันทึกเก็บไว้ ผู้สนับสนุนจึงไม่มีอะไรจะยื่น |

แถวสุดท้ายจับโรงงานที่ขายอุปกรณ์ในตลาดอื่นมาหลายปี หากข้อมูลข้อร้องเรียนไม่เคยถูกเก็บในรูปแบบที่ผู้สนับสนุนใช้ได้ ชุดเอกสารออสเตรเลียก็เริ่มจากศูนย์แม้สินค้าจะมีประวัติอยู่แล้ว

## เหตุใด Australia จึงมักอยู่ท้ายรายการ

สามตลาด สามคอขวดที่ต่างกัน วางเทียบกันแล้วเหตุผลที่ Australia หลุดไปอยู่ท้ายลำดับก็ชัดขึ้น

| ตลาด | อะไรเป็นประตูกั้นการเปิดตัว | ใครถือความรับผิดชอบ |
|---|---|---|
| EU | ผู้รับผิดชอบที่ระบุชื่อบนผลิตภัณฑ์ | ผู้ประกอบการใน EU ซึ่งได้รับการแต่งตั้งจากผู้ขาย |
| ญี่ปุ่น | เส้นทาง PSE และผู้นำเข้าในญี่ปุ่น | ผู้นำเข้า ซึ่งยื่นต่อ METI |
| Australia | รายการใน ARTG บนทะเบียนสาธารณะ | ผู้สนับสนุน ซึ่งรับผิดชอบทางกฎหมายต่ออุปกรณ์ |

ประตูของ EU และญี่ปุ่นเปิดได้ด้วยเอกสารและการแต่งตั้ง ประตูของ Australia คือรายการในทะเบียนสาธารณะที่ขึ้นกับความยินดีของบุคคลที่สามที่จะแบกความรับผิดทางกฎหมาย และขึ้นกับหลักฐานที่ต้องผ่านการประเมิน นั่นคือเหตุผลที่แบรนด์ซึ่งเปิดตัวในยุโรปและญี่ปุ่นในไตรมาสเดียวกันมักมาถึง Australia ช้ากว่าหนึ่งปี

หากคุณมุ่งไปยังตลาดเหล่านั้นมากกว่าหนึ่งแห่ง [วิธีที่หน่วยงานกำกับดูแลจัดประเภทอุปกรณ์ IPL สำหรับใช้ที่บ้าน](/blog/how-regulators-classify-home-ipl) ได้วางสี่เส้นทางเทียบกันไว้ และ [ภาพรวมการกำกับดูแลระดับโลก](/blog/08-global-regulatory-landscape-for-ipl-devices) คือแผนที่ว่าตลาดใดมีประตูกั้นด้วยใบรับรอง การแจ้ง หรือรายการในทะเบียน

## สิ่งที่เราทำ และสิ่งที่เราไม่ทำ

เราจัดทำ technical file รายงานการทดสอบ ผลวัดสมรรถนะที่รองรับข้อกำหนด เอกสารการบริหารความเสี่ยง อาร์ตเวิร์กฉลากและ IFU และหลักฐานการผลิตที่ผู้สนับสนุนขอ เราไม่ทำหน้าที่เป็นผู้สนับสนุนในออสเตรเลีย เราไม่ถือรายการใน ARTG และเราไม่ใส่เลข TGA ไว้บนหน้าใดของเว็บไซต์นี้หากเราไม่มีรายการในทะเบียนรองรับอยู่เบื้องหลัง

Australia ยังเป็นตลาดที่ข้อมูลคำค้นของเราเองชี้ว่ามีความต้องการสูงที่สุดนอกสหรัฐอเมริกาและเยอรมนี ซึ่งเป็นเหตุผลดีที่ควรทำงานด้านการปฏิบัติตามกฎระเบียบให้ถูกต้องแทนที่จะมองเป็นแค่ช่องที่ต้องติ๊ก [กระบวนการ private label](/services/private-label) ระบุว่าเอกสารใดออกในขั้นตอนใด และ [ช่วงรุ่นสินค้า](/products) แสดงแพลตฟอร์มที่มีหลักฐานการทดสอบซึ่งผู้สนับสนุนจะเริ่มต้นใช้ได้แล้ว
