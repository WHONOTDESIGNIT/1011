**Réponse courte :** les appareils IPL domestiques circulent dans le commerce sous au moins deux codes tarifaires, 8510.30 et 8543.70, parce qu'aucune des deux positions n'a été rédigée en pensant à ce produit. Le code décide du droit de douane, du traitement préférentiel et des obligations déclaratives, le courtier en douane prend la décision, et la seule chose qu'un acheteur doit exiger, c'est que tous les documents de l'envoi concordent avec lui.

## Les deux positions, et pourquoi les deux apparaissent

La première position couvre les rasoirs, les tondeuses et les appareils d'épilation, et sa rédaction même suppose un moteur électrique incorporé. Cela convient à un rasoir. Un appareil IPL n'a aucun moteur : une lampe au xénon, un banc de condensateurs, une carte de commande et un système de refroidissement.

C'est cet écart qui fait apparaître la position résiduelle dans le même commerce : les machines et appareils électriques ayant une fonction propre, non dénommés ni compris ailleurs. C'est la place honnête d'un produit que le tarif n'avait pas anticipé.

Les deux codes finissent dans de vrais documents. Sur une commande de 504 unités à boîtier dégradé, la déclaration d'exportation portait le code des appareils d'épilation, les pages produit portaient le même numéro en tant que code américain, et une seconde liste de colisage portait le code résiduel. Deux documents, un envoi, deux réponses.

Rien de tout cela n'est inhabituel dans cette catégorie de produits. Ce qui est inhabituel, c'est de le repérer avant la déclaration plutôt qu'après.

## Pourquoi le code n'est pas un détail administratif

Le droit de douane est fonction de trois choses : le code, l'origine et le programme auquel l'origine donne droit. Changez l'un et le chiffre du coût rendu bouge.

| Ce que le code affecte | Pourquoi |
|---|---|
| Taux de droit de douane | Des positions différentes portent des taux différents, et l'écart est souvent plus grand que le fret |
| Traitement préférentiel | Les accords de libre-échange se négocient position par position |
| Programmes tarifaires additionnels | Les mesures liées à l'origine s'appliquent par position, pas par description de produit |
| Licences et normes à l'importation | Certaines destinations rattachent une surveillance du marché ou un enregistrement à des positions précises |
| Déclarations statistiques et contingents | La déclaration statistique de l'importateur est déposée par code |

La question du code n'est donc pas une affaire de propreté administrative. C'est la différence entre un coût rendu calculé et un coût rendu deviné.

## Qui décide réellement

Le courtier en douane déclare, et la déclaration est la sienne à signer. Ce n'est pas une formalité qu'on contourne ; c'est la raison pour laquelle un courtier refusera d'utiliser un code qu'il ne peut pas défendre.

Trois conséquences pour un acheteur :

- **Demandez le code par écrit avant que la commande ne soit passée**, pas sur la facture commerciale une fois les marchandises parties.
- **Demandez contre quel tarif douanier il est vérifié.** Un code juste sur le tarif américain n'est pas automatiquement juste pour la déclaration d'exportation dans le pays d'origine. Ce sont deux tarifs différents, et ils ont le droit de ne pas concorder.
- **Demandez ce qui se passe si le modèle change.** Ajoutez un moteur pour une tête rotative, retirez la lampe pour une variante LED, et la position peut suivre.

Un fournisseur qui répond aux trois l'a déjà fait. Un fournisseur qui dit « nous utilisons toujours un seul code » vous a dit qu'il n'a jamais été audité.

## La règle de cohérence

C'est la partie qui bloque les envois, et elle est entièrement du ressort d'une usine : **la facture commerciale, la liste de colisage, le certificat d'origine et la déclaration doivent tous porter le même code, et les marchandises doivent correspondre à la description qui le sous-tend.**

Un envoi où la facture indique une position et la déclaration une autre est une divergence à la frontière. Peu importe lequel des deux avait raison.

L'autre moitié, c'est la description. Une description déclarée d'« appareil d'épilation » passe confortablement sous une position et maladroitement sous l'autre. Les descriptions et les codes doivent être choisis ensemble.

## Ce que nous faisons sur nos commandes

Nous gardons le code sur les documents commerciaux et le rapprochons de la déclaration avant que le courtier ne dépose, ce qui est la façon dont la divergence de cette commande de 504 unités a été attrapée plutôt que découverte au port. Nous utilisons le même code sur les pages produit, pour qu'un acheteur qui lit le site et un courtier qui lit la facture regardent le même numéro.

Ce que nous ne faisons pas, c'est annoncer à un client le montant de ses droits d'importation. Cette réponse dépend de son tarif douanier, de ses règles d'origine et de l'avis de son propre courtier, et ce n'est pas nous qui signons la déclaration.

## Ce qu'il faut demander avant le premier envoi

1. Quel code figurera sur la facture commerciale, et contre quel tarif a-t-il été vérifié ?
2. Ce code a-t-il déjà servi sur un envoi précédent de ce modèle exact, et est-il passé sans demande de renseignement ?
3. Si le modèle change, qui revérifie le code, et quand ?
4. La facture, la liste de colisage, le certificat d'origine et la déclaration peuvent-ils être confrontés entre eux avant le dépôt ?

Quatre questions, une page de réponses, classée avec la commande. C'est moins cher qu'un reclassement.
