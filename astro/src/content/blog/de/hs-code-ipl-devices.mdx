**Kurz gesagt:** Heim-IPL-Geräte zirkulieren im Handel unter mindestens zwei Tarifcodes, 8510.30 und 8543.70, weil keine der beiden Positionen mit diesem Produkt im Sinn geschrieben wurde. Der Code entscheidet über Zoll, Präferenzbehandlung und Meldepflichten, der verantwortliche Zollagent trifft die Entscheidung, und worauf ein Käufer bestehen sollte, ist, dass jedes Dokument in der Sendung damit übereinstimmt.

## Die beiden Positionen und warum beide auftauchen

Die erste Position umfasst Rasierer, Haarschneider und Haarentfernungsgeräte, und ihr eigener Wortlaut setzt einen eingebauten Elektromotor voraus. Das passt auf einen Rasierer. Ein IPL-Gerät hat überhaupt keinen Motor: eine Xenonlampe, eine Kondensatorbank, eine Steuerplatine und ein Kühlsystem.

Diese Diskrepanz ist der Grund, warum im selben Handel die Auffangposition auftaucht: elektrische Maschinen und Apparate mit eigener Funktion, anderweitig weder genannt noch inbegriffen. Sie ist der ehrliche Ort für ein Produkt, das der Tarif nicht vorgesehen hat.

Beide Codes landen in echten Papieren. Bei einer Bestellung über 504 Geräte mit Gradient-Gehäuse trug die Exportanmeldung den Code für Haarentfernungsgeräte, die Produktseiten trugen dieselbe Nummer als US-Code, und eine zweite Packliste trug den Auffangcode. Zwei Dokumente, eine Sendung, zwei Antworten.

Daran ist in dieser Produktkategorie nichts ungewöhnlich. Ungewöhnlich ist, es vor der Anmeldung zu bemerken und nicht danach.

## Warum der Code kein Formalitätsdetail ist

Der Zoll ist eine Funktion aus drei Dingen: dem Code, dem Ursprung und dem Programm, für das der Ursprung qualifiziert ist. Ändern Sie eines, und die Zahl in den Landed Cost (Einfuhrkosten) bewegt sich.

| Was der Code beeinflusst | Warum |
|---|---|
| Zollsatz | Unterschiedliche Positionen tragen unterschiedliche Sätze, und die Differenz ist oft größer als die Fracht |
| Präferenzbehandlung | Freihandelsabkommen werden pro Position verhandelt |
| Zusätzliche Tarifprogramme | Ursprungsbezogene Maßnahmen werden nach Position angewandt, nicht nach Produktbeschreibung |
| Einfuhrlizenzen und Standards | Manche Bestimmungsländer knüpfen Marktüberwachung oder Registrierung an bestimmte Positionen |
| Statistische Meldung und Quote | Die eigene Meldung des Importeurs wird nach Code eingereicht |

Die Codefrage ist also keine administrative Ordnungsliebe. Sie ist der Unterschied zwischen einem Landed Cost, der berechnet wurde, und einem, der geraten wurde.

## Wer tatsächlich entscheidet

Der verantwortliche Zollagent (broker of record) gibt die Anmeldung ab, und die Anmeldung ist seine zu unterzeichnen. Das ist keine Formalie, um die man herumgeht; es ist der Grund, warum ein Zollagent einen Code ablehnt, den er nicht verteidigen kann.

Daraus folgen drei Dinge für einen Käufer:

- **Verlangen Sie den Code schriftlich, bevor die Bestellung aufgegeben wird**, nicht erst auf der Handelsrechnung, nachdem die Ware verschifft ist.
- **Fragen Sie, gegen welchen Tarif er geprüft wird.** Ein Code, der im US-Tarif richtig ist, ist nicht automatisch richtig für die Exportanmeldung im Ursprungsland. Das sind zwei verschiedene Tarifwerke, und sie dürfen voneinander abweichen.
- **Fragen Sie, was passiert, wenn sich das Modell ändert.** Fügen Sie einen Motor für einen rotierenden Kopf hinzu, entfernen Sie die Lampe für eine LED-Variante, und die Position kann sich mitbewegen.

Ein Lieferant, der alle drei beantwortet, hat das schon gemacht. Ein Lieferant, der sagt „wir benutzen immer einen Code“, hat Ihnen gesagt, dass er noch nie geprüft wurde.

## Die Konsistenzregel

Das ist der Teil, der Sendungen erwischt, und er liegt vollständig in der Kontrolle einer Fabrik: **Handelsrechnung, Packliste, Ursprungszeugnis und Anmeldung müssen alle denselben Code tragen, und die Ware muss zu der Beschreibung dahinter passen.**

Eine Sendung, bei der die Rechnung eine Position nennt und die Anmeldung eine andere, ist eine Abweichung an der Grenze. Es spielt keine Rolle, welche von beiden richtig war.

Die andere Hälfte ist die Beschreibung. Eine angemeldete Beschreibung „Haarentfernungsgerät“ sitzt unter der einen Position bequem und unter der anderen unglücklich. Beschreibungen und Codes müssen zusammen gewählt werden.

## Was wir bei unseren Bestellungen tun

Wir führen den Code auf den Handelsdokumenten und gleichen ihn vor der Einreichung durch den Zollagenten mit der Anmeldung ab; so wurde die Abweichung in jener Bestellung über 504 Einheiten bemerkt und nicht erst im Hafen entdeckt. Wir verwenden denselben Code auf den Produktseiten, damit ein Käufer, der die Website liest, und ein Zollagent, der die Rechnung liest, dieselbe Nummer sehen.

Was wir nicht tun, ist einem Kunden zu sagen, wie hoch sein Einfuhrzoll sein wird. Diese Antwort hängt von seinem Tarif, seinen Ursprungsregeln und der Auffassung seines eigenen Zollagenten ab, und wir sind nicht die Partei, die die Anmeldung unterzeichnet.

## Was vor der ersten Sendung zu fragen ist

1. Welcher Code erscheint auf der Handelsrechnung, und gegen welchen Tarif wurde er geprüft?
2. Wurde dieser Code bei einer früheren Sendung genau dieses Modells verwendet, und wurde sie ohne Rückfrage abgefertigt?
3. Wenn sich das Modell ändert, wer prüft den Code erneut, und wann?
4. Können Handelsrechnung, Packliste, Ursprungszeugnis und Anmeldung vor der Einreichung gegeneinander geprüft werden?

Vier Fragen, eine Seite Antworten, zur Bestellung abgelegt. Das ist billiger als eine Neueinreihung.
